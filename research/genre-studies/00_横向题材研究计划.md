# 横向题材研究计划｜先独立研究，再跨题材比较

> 状态：Active
> 目的：避免以“重生”为锚点推演所有题材。先对多个高频短剧题材做相对独立的机制研究，再进入跨题材比较与素材适配性归纳。
> 研究边界：当前重点是 Material Selection（素材选择）与 Premise / Genre Mechanism（前提 / 题材机制），暂不把 Plot / Story Dynamics（剧情动力）作为主研究对象。

---

## 1. 研究原则

### 1.1 Independent Pass First｜先独立研究

每个题材先回答“它自身是什么、天然提供什么”，不先问“它和重生有什么不同”。

目的：

- 降低 anchoring（锚定）；
- 避免把重生研究出的变量强行套到其他题材；
- 允许出现新的机制维度；
- 保留真正的题材特异性。

### 1.2 Shared Questions, Open Ontology｜统一问题，不锁死答案空间

为了后续可比，每个题材使用同一组研究问题，但允许答案落在现有体系之外。

统一问题：

1. 这个市场题材标签实际包含哪些常见前提？
2. 它改变了哪些初始条件？
3. 它天然提供哪些 Material Affordances（素材可供性）？
4. 它天然制造哪些信息结构、优势 / 约束、关系或世界规则？
5. 它可能提供哪些 Audience-side Value（观众侧价值）？
6. 哪些机制已有科学 / 媒体心理学 / 叙事研究支持？
7. 哪些只是工作假设？
8. 它对短剧最有价值的“低成本叙事资源”是什么？
9. 它最常见的失效模式是什么？
10. 有哪些机制是该题材特异的，哪些只是通用故事机制？

### 1.3 Evidence Discipline｜证据纪律

沿用研究执行协议：

- [已验证事实]
- [直接叙事证据]
- [迁移性推断]
- [工作假设]
- [文献检索未完成]
- [机制层阶段性暂停：非文献穷尽]

不要因为某个题材市场上常见，就把其心理机制当作已验证事实。

## 2. 第一批横向题材

第一批优先选择结构差异明显、且短剧中常见的题材：

### A. 系统

重点观察：

- 外部规则装置；
- 能力 / 资源 / 信息授予；
- 任务—奖励—惩罚结构；
- progression visibility（成长可视化）；
- agency 与依赖系统之间的张力。

### B. 穿越

重点观察：

- 身份 / 世界位置转换；
- modern knowledge / cultural asymmetry；
- stranger-in-world；
- adaptation / belonging；
- 优势与劣势并存。

### C. 神豪

重点观察：

- Resource Advantage；
- status mobility；
- visible payoff；
- social comparison；
- 消费 / 支配 / 反转关系的低成本兑现。

### D. 战神 / 隐藏大佬

重点观察：

- latent power（潜在强能力）；
- hidden identity（隐藏身份）；
- recognition gap（认知差）；
- humiliation → reveal / reversal；
- competence expectation。

### E. 复仇

重点观察：

- grievance / injustice；
- clear target；
- moral accounting；
- delayed retaliation；
- planning / reveal / payoff；
- 是否需要超自然前提。

### F. 末世

重点观察：

- world-rule disruption；
- scarcity；
- threat density；
- survival choice；
- alliance / betrayal；
- resource competition；
- 状态变化速度。

### G. 甜宠 / 霸总

重点观察：

- relationship architecture；
- status / resource asymmetry；
- attachment / intimacy；
- exclusivity；
- misunderstanding / recognition；
- emotional payoff frequency。

## 3. 每个题材的固定研究模板

每个题材建立独立目录，至少包含：

### 01｜题材边界与作品现实检查

- 市场标签如何使用；
- 常见变体；
- 典型作品 / 样本；
- 哪些元素是必要的，哪些只是高频伴随。

### 02｜Premise / Material Affordance

- 初始条件变化；
- 可供性；
- 信息结构；
- 优势 / 约束；
- 关系 / 世界规则；
- 能直接产生哪些可写资源。

### 03｜Audience-side Mechanism

- 可能的心理价值；
- 科学映射；
- 直接证据 vs 迁移性推断；
- 题材特异性检验。

### 04｜短剧适配性

重点不做主观“好写 / 不好写”，而检查：

- 初始异常是否强；
- 是否天然产生 open question；
- 是否容易形成信息不对称；
- 是否容易产生频繁 state change；
- 是否容易形成可见 payoff；
- 是否支持连续 escalation；
- 是否能低成本产生下一集问题；
- 是否存在高重复 / 快速耗尽风险。

### 05｜阶段结论

- 当前最可能的核心机制；
- 尚未解决的问题；
- 文献停点；
- 是否进入跨题材比较。

---

## 4. 跨题材比较的启动条件

在第一批题材中至少完成 4–5 个独立研究后，再进入 cross-genre comparison。

不要边研究第 2 个题材边重写“总分类”。

启动比较后，比较单位至少包括：

- Initial Condition Delta（初始条件变化）
- Information Asymmetry（信息不对称）
- Advantage / Constraint
- Goal Affordance（目标可供性）
- Conflict Affordance（冲突可供性）
- State-change Affordance（状态变化可供性）
- Payoff Affordance（兑现可供性）
- Escalation Capacity（升级容量）
- Novelty / Exhaustion Risk（新鲜度 / 耗尽风险）
- Production Affordance（制作可供性，后续阶段）
- Audience-side Value（观众侧价值）

比较阶段的目标不是选“最好题材”，而是建立：

> **不同题材分别低成本提供哪些叙事资源，在什么条件下适合短剧。**

---

## 5. 推荐研究顺序

为了最大化结构差异、避免相似题材连续造成混淆：

1. 系统
2. 复仇
3. 末世
4. 神豪
5. 穿越
6. 战神 / 隐藏大佬
7. 甜宠 / 霸总

重生作为已有深度样本，不重新从头研究；待至少完成 4 个新题材后，与其他题材一起进入比较。
