Knowledge Structure Mapping · Lesson 0004

Relation Typing（关系定型）｜第一单元

这一单元只解决一个问题：两个节点之间的箭头，到底表示什么关系？

1. Relation Typing 是什么？

Node Typing： “这个节点是什么？” Relation Typing： “节点 A 与节点 B 之间，是什么语义关系？”

不能因为两个节点“有关”，就画一条没有标签的父子线。先判断 relation type（关系类型），再决定它们是否构成 hierarchy（层级）。

2. 第一组只学 3 种关系

INSTANCE_OF（实例属于类）

测试：A 是 B 的一个具体实例吗？

形式直觉：x ∈ A

例：某一部具体作品 INSTANCE_OF 重生短剧。

IS_A / SUBCLASS_OF（是一种 / 子类）

测试：任何 A，在定义上都应该是 B 吗？

形式直觉：A ⊆ B

例：Information Advantage IS_A Advantage。

PART_OF（部分—整体）

测试：A 是构成 B 的一部分，而不是一种 B 吗？

例：资产抽取模块 PART_OF 影视生产工作流。

3. 最容易混淆：INSTANCE_OF vs IS_A

INSTANCE_OFIS_A
左边节点具体实例类 / 概念
右边节点类 / 概念更一般的类 / 概念
典型问法“它是这一类中的一个具体对象吗？”“这一类本身是不是另一类的子类？”

对比：

林凡 INSTANCE_OF 主角 主角 IS_A 角色

“林凡”是具体人物；“主角”与“角色”都是类别层面的概念。

4. IS_A vs PART_OF

这两个最容易因为都能画成“上下结构”而混淆。

金毛犬 IS_A 狗 车轮 PART_OF 汽车

金毛犬本身就是一种狗；车轮不是一种汽车，它只是汽车的一部分。

5. Direction（方向）也属于关系的一部分

具体实例 → INSTANCE_OF → 类 子类 → IS_A → 上位类 部分 → PART_OF → 整体

把箭头反过来，语义就变了。

6. 第一轮练习

A

《逆流人生》是一部具体的重生短剧。

《逆流人生》 —— ? —— 重生短剧

B

信息优势是一种优势。

信息优势 —— ? —— 优势

C

角色资产抽取模块是影视生产工作流的一部分。

角色资产抽取模块 —— ? —— 影视生产工作流

D｜边界题

林凡是这部剧的主角；主角是一种角色。

林凡 —— ? —— 主角

主角 —— ? —— 角色

7. 本单元只带走一句话

不要先画父子关系。 先问： “这是 INSTANCE_OF、IS_A，还是 PART_OF？”
