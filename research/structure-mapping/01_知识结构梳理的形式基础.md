# Knowledge Structure Mapping（知识结构梳理）的形式基础

> 状态：v0.1
> 目标：为未来的层级 / 结构梳理 Skill 建立数学、知识组织与本体论支持材料。
> 当前结论：Set Theory（集合论）是基础，但不够。更合适的理论栈是 Set Theory + Order Theory（序理论）+ Mereology（部分论）+ Ontology Engineering（本体工程）+ Facet Analysis（分面分析）+ Graph Representation（图表示）。

## 1. 研究问题

真正的问题不是“怎么画一棵树”，而是：给定概念、变量、机制、阶段与关系，怎样判断哪些是层级，哪些不是；哪些节点可以并列，哪些来自不同分类轴；什么时候该用 Tree（树）、DAG（有向无环图）、Facet Model（分面模型）或 Labeled Graph（带标签关系图）。

## 2. Set Theory（集合论）：必要但不足

### [已验证事实] membership（属于）与 subset（子集）是不同关系

`x ∈ A` 表示元素属于集合；`A ⊆ B` 表示集合包含。RDF Schema 对应地区分 `rdf:type`（instance-of）与 `rdfs:subClassOf`（subclass-of），后者表达类之间的包含并具有传递性。

来源：W3C RDF 1.2 Schema — https://www.w3.org/TR/rdf12-schema/

对 Skill 的要求：禁止把 instance-of 和 subclass-of 无标签地画成同一种父子关系。

### [已验证事实] Partition（划分）有严格条件

集合的 partition 要求非空、两两不相交、并且合起来覆盖全集。数学上对应 pairwise disjoint（两两互斥）+ collectively exhaustive（合起来穷尽）。

来源：Encyclopedia of Mathematics, Partition — https://encyclopediaofmath.org/wiki/Partition

对 Skill 的要求：当声称“完整分类”时，必须检查同一划分标准、是否互斥、是否穷尽。不是所有 taxonomy 都要求兄弟节点构成严格 partition。

## 3. Order Theory（序理论）：更接近 hierarchy 的数学核心

### [已验证事实] hierarchy 更适合用 partial order（偏序）理解

Partial Order（偏序）具有 reflexive（自反）、antisymmetric（反对称）、transitive（传递）三种性质，并允许某些节点不可比较。

来源：Stanford Encyclopedia of Philosophy — https://plato.stanford.edu/entries/qt-quantlog/supplement.html
来源：Encyclopedia of Mathematics — https://encyclopediaofmath.org/wiki/Partially_ordered_set

这意味着知识层级不必是一条线；A 和 B 可以都位于 C 之下，但 A、B 彼此不可比较。

### [已验证事实] 一个节点可以有多个上位节点

RDF Schema 允许一个 class 同时是多个 class 的 subclass。

因此，层级结构不应默认是一棵 Tree（树）。更稳妥的形式默认是 DAG / partial-order graph（有向无环图 / 偏序图）；只有确认每个节点最多一个直接父节点时才退化为 Tree。

### [工作综合] Hasse-diagram thinking（Hasse 图思维）

偏序的 Hasse Diagram 通常省略自反边与可由传递性推出的边。迁移到知识梳理，可理解为：优先显示“最近的直接上位关系”，避免把所有祖先边画出来。

## 4. Set inclusion 不等于 semantic is-a

### [已验证事实] 集合包含只是 is-a 的线索，不总是充分条件

Smith et al.（2005）指出，把 `is_a` 简单等同于集合包含会出现 contingent inclusion（偶然包含）和时间变化导致的误判。

来源：Smith et al. (2005), Relations in biomedical ontologies — https://doi.org/10.1186/gb-2005-6-5-r46

对 Skill 的要求：不能仅因为“A 的当前实例都落在 B 中”就判定 A is-a B；还要判断这是定义性的 subtype，还是偶然包含、阶段关系、角色状态或其他关系。

### [已验证事实] 两个 class 可以 extension（外延）相同但 concept 不同

W3C RDF 1.2 明确区分 class 与其 class extension；两个 class 即使当前具有相同 instances，也可以仍然是不同 class。

因此 Structure Mapping 不能只靠“包含哪些例子”判断概念等价。

## 5. Ontology Engineering（本体工程）：检查 is-a 是否被滥用

### [已验证事实]

Guarino & Welty 的 OntoClean 专门用于审查 taxonomy 中 subsumption / is-a 的误用，并借助 identity（同一性）、rigidity（刚性）、unity（整体性）、dependence（依赖）等元性质验证分类。

来源：Guarino & Welty (2002) — https://doi.org/10.1145/503124.503150
来源：Welty & Guarino (2001) — https://doi.org/10.1016/S0169-023X(01)00030-1

对 Skill 的核心启发：每次把 A 放到 B 下面时，都要问“这真的是一种 B，还是只是有关、处于阶段、承担角色、依赖或包含？”

## 6. Mereology（部分论）：part-of 不是 subclass-of

### [已验证事实]

Mereology 是专门研究 part–whole（部分—整体）关系的理论。part-of 与 is-a 是不同关系。

来源：Stanford Encyclopedia of Philosophy, Mereology — https://plato.stanford.edu/entries/mereology/
来源：Smith (1996), Mereotopology — https://doi.org/10.1016/S0169-023X(96)00015-8

对 Skill 的要求：`A is-a B` 与 `A part-of B` 必须显式分开，不能都画成“下一级”。

## 7. Facet Analysis（分面分析）：解释“为什么有些东西不能并列”

### [已验证事实]

Facet Analysis 建立在 logical division（逻辑划分）的传统上。经典逻辑划分强调：同一次划分应该使用 single principle of division（单一划分原则）。

来源：Hjørland (2013), Facet analysis — https://doi.org/10.1016/j.ipm.2012.10.001
来源：Broughton (2013), Faceted Classification as a General Theory for Knowledge Organization — https://doi.org/10.17821/srels/2013/v50i6/43823

这直接解释了我们此前 Premise Architecture 的错误：Advantage 属于 Relative Effect（相对效应），Transformation 属于 Operation（变化方式），Relationship 属于 Locus（改变落点）；它们来自不同 facet，不能作为同轴 siblings。

## 8. SKOS：hierarchical 与 associative relation 必须分开

### [已验证事实]

W3C SKOS 区分 hierarchical relations（broader / narrower）与 associative relation（related），并区分 direct broader 与 transitive broader。

来源：W3C SKOS Reference — https://www.w3.org/TR/skos-reference/

对 Skill 的要求：两个概念“关系很强”不等于它们必须进入父子层级。

## 9. Graph / Knowledge Graph：复杂知识不是一棵树

### [已验证事实]

Knowledge Graph 常被表示为 directed, labeled, multi-relational graph（有向、带标签、多关系图）。

来源：Kejriwal (2022), Knowledge Graphs: A Practical Review — https://doi.org/10.3390/info13040161

当一组节点同时存在 is-a、part-of、causes、precedes、related-to、depends-on 等关系时，不应强制输出单一 hierarchy tree，而应使用带关系标签的图。

## 10. Formal Concept Analysis（形式概念分析）：高级支持

### [已验证事实]

Formal Concept Analysis（FCA）基于 Order Theory / Lattice Theory，通过 object–attribute relation（对象—属性关系）构建 formal concepts 与 concept lattice（概念格）。

来源：Ganter & Wille, Formal Concept Analysis: Mathematical Foundations — https://link.springer.com/book/10.1007/978-3-031-63422-2

### [工作综合]

FCA 对未来自动化 Structure Mapping 很有潜力，尤其适用于“对象 × 属性矩阵 → 自动概念层级”；但对 v1 Agent 梳理来说复杂度过高，不作为核心步骤。

## 11. 命名冲突：Structure-Mapping 已是认知科学术语

### [已验证事实]

Dedre Gentner 的 Structure-Mapping Theory（结构映射理论）是 analogy（类比）研究中的经典理论，研究 base domain 到 target domain 的关系结构映射，并不是“知识层级梳理”。

来源：Gentner (1983) — https://doi.org/10.1207/s15516709cog0702_3

### [工作建议]

未来 Skill 建议命名为 `knowledge-structure-mapping`（知识结构梳理），避免与 Gentner 的 Structure-Mapping Theory 混淆。

## 12. 当前理论栈

```text
Set Theory（集合论）
membership / subset / partition
        ↓
Order Theory（序理论）
partial order / incomparability / multiple parents
        ↓
Ontology Engineering + Mereology
is-a / instance-of / part-of
        ↓
Facet Analysis（分面分析）
检查是否混用了不同划分轴
        ↓
SKOS / Knowledge Graph
决定 hierarchy / association / multi-relational graph
```

## 13. 可转化为 Skill 的强规则

### [工作综合]

1. Node typing（节点定型）：instance、class、dimension、value、process、relation？
2. Relation typing（关系定型）：instance-of、is-a、part-of、facet、sequence、causal、associative？
3. Single-axis check（单轴检查）：准备并列的节点是否来自同一划分标准？
4. Partition claim check（划分声明检查）：声称“完整分类”时是否互斥且穷尽？
5. Partial-order check（偏序检查）：是否允许多个父节点和不可比较节点？
6. Tree-or-graph decision（树 / 图决策）：关系类型混合时不强制输出树。
7. Current-node localization（当前节点定位）：明确父、同级、子 / 下游关系。
8. Conflict marking（冲突标记）：无法确定时保留 uncertainty，不伪造层级。

## 14. 研究状态

[较强支持] instance-of 与 subclass-of 必须区分；part-of 与 is-a 必须区分；partial order 比 total order 更接近一般 hierarchy；hierarchical 与 associative relation 应分离；facet analysis 对不同分类轴混写有直接价值；复杂多关系知识更适合 labeled graph。

[工作综合] 本项目采用 Set Theory + Order Theory + Ontology + Mereology + Facet Analysis + Graph 作为知识结构梳理的基础理论栈。

[文献检索未完成] 人类理解中 Tree / DAG / concept map / graph 的相对认知效果；层级深度与分支宽度对 cognitive load 的影响；LLM 自动构建 taxonomy / ontology 的常见错误与评估；“研究问题树”而非概念 taxonomy 的形式规则。
