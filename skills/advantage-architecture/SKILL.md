# Advantage Architecture（优势架构）

Analyze a favorable asymmetry created by the story premise.

## Context pointers（上下文指针）

- Read `../../research/00_短剧题材研究_层级地图.md` for the current premise-layer Advantage Architecture（优势架构） variables. This is the single source of truth for the active variable set.
- Read `../../research/genre-studies/重生/15_优势架构的科学研究映射.md` only when scientific grounding for an advantage dimension is needed.
- Treat `16_优势架构第二轮_优势类型可用性与行动空间.md` as historical research context when needed; its conversion / action material is outside the default premise-layer scope.

## Process（执行流程）

### ◆ Establish the benchmark（建立参照系）

Identify who or what the protagonist is advantaged relative to.

**Completion criterion:** the advantage has an explicit reference frame; “the protagonist is stronger” is not sufficient.

### ◆ Identify the favorable asymmetry（识别正向不对称）

State exactly what condition the protagonist has more of, earlier access to, or fewer constraints around.

**Completion criterion:** the advantage is stated as an initial-condition difference, not as a later payoff.

### ◆ Characterize the advantage（刻画优势）

Use the current variables defined in the premise research map. Load deeper research only for the dimensions actually needed.

**Completion criterion:** the relevant current variables are resolved or explicitly unknown; no parallel taxonomy is invented inside this Skill.

### ◆ Separate neighboring mechanisms（分离邻近机制）

Separate:

- Constraint / Disadvantage Architecture（约束 / 劣势架构）;
- Trade-off Architecture（交换 / 代价架构）;
- Payoff（收益）;
- downstream Advantage Conversion（优势转化） and Plot Causality（剧情因果）.

**Completion criterion:** results and later actions are not backfilled into the definition of the advantage itself.

## Output（输出）

Return:

- benchmark / reference frame;
- favorable asymmetry;
- current advantage characterization;
- overlaps with constraint or trade-off;
- deferred payoff / plot questions.
