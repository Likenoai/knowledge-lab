Knowledge Structure Mapping · Final Core Module

Current-node Localization 与 Conflict / Unknown

前面的模块解决“结构是否正确”；这一课解决最后一个实用问题：当我们正在研究某个具体节点时，怎样准确描述它在整个知识结构中的位置，并保留尚未解决的不确定性。

1. Current Node（当前节点）不是“当前页面标题”

Current Node 是当前分析焦点在结构中的语义位置。

Current Node: Node Type: Relation to Parent: Parent: Siblings under same criterion: Children / narrower concepts: Orthogonal facets: Upstream prerequisites: Downstream consequences: Unresolved relation conflicts:

这份模板的目的不是把所有字段都填满，而是防止把不同方向的关系混成“父子”。

2. Parent（父 / 直接上位）必须带 Relation Type

不要只写：

Parent: Relative Effect

更准确：

Current Node: Advantage Node Type: Value Relation to Parent: VALUE_OF Parent: Relative Effect

“Parent”只是结构位置；真正的语义由 Relation Type 决定。

3. Siblings（同级）必须满足同级资格

Current Node: Advantage Parent: Relative Effect Relation: VALUE_OF Valid siblings: - Disadvantage - Trade-off

因为它们在同一个 Dimension 下，以同一种 VALUE_OF 关系连接，并回答同一个问题。

Relationship 不是 sibling，因为它属于 Locus。

4. Children / Narrower Concepts（子节点 / 更窄概念）

“Children”是一个视觉位置词，不是固定 Relation Type。

因此要继续标记：

Information Advantage IS_A Advantage

这里 Information Advantage 可以被视为 Advantage 的 narrower concept / subtype；但如果关系尚未验证，不应强行声明 IS_A。

5. Orthogonal Facets（正交分面）

Orthogonal Facet 指：与当前节点有关，但不与它竞争同一轴位置的其他描述维度。

Current Node: Advantage belongs to: Relative Effect Orthogonal facets: - Locus - Operation

这能防止把“不同轴上的相关节点”误当 sibling。

6. Upstream / Downstream 不是 Parent / Child

Upstream = 前置条件、来源、先行机制、输入 Downstream = 后果、结果、后续机制、输出 Parent / Child = hierarchy / classification position

例如：

重生 → ENABLES → 信息优势

重生可以是信息优势的 upstream mechanism，但它不是信息优势的 parent。

7. Current-node Localization 的核心价值

它把“当前研究位置”拆成多个方向：

方向典型问题
Up（上位）我属于哪个更一般结构？通过什么关系？
Side（同轴横向）我有哪些真正 siblings？
Down（下位）有哪些 subtype / narrower / component？
Orthogonal（正交）有哪些其他 facet？
Upstream（上游）什么产生 / 支持 / 约束我？
Downstream（下游）我会导致 / 使能 / 约束什么？

8. Unknown（未确定）必须是一等状态

成熟的知识结构不要求每条边立刻有答案。

UNKNOWN = 当前证据不足，无法可靠判定 Relation Type

UNKNOWN 不是失败，而是避免伪造结构。

9. Conflict（冲突）与 Unknown 不同

状态含义
UNKNOWN证据不足，尚不能判断
CONFLICT存在互相不兼容的结构证据或声明
MULTIPLE_CANDIDATES存在多个可能关系，尚未排除
UNRESOLVED问题已识别，但暂未解决

10. Conflict 的常见来源

Relation Conflict

一处说 A IS_A B，另一处说 A PART_OF B。

Axis Conflict

同一节点在两个不兼容 facet 中被当作同轴 value。

Cycle Conflict

A IS_A B，B IS_A C，C IS_A A，但三者又被视为不同概念。

Granularity Conflict

同一层混入过粗和过细节点，导致比较单位不一致。

11. 最小 Current-node 模板

Current Node: Node Type: Parent: Relation to Parent: Same-axis Siblings: Children / Narrower: Orthogonal Facets: Upstream: Downstream: Unknowns: Conflicts:

12. 最终执行链已经闭合

Research Question ↓ Node Extraction ↓ Node Typing ↓ Relation Typing ↓ Sibling / Single-axis Check ↓ Partition Claim Check ↓ Partial-order / Multiple-parent Check ↓ Structure Representation ↓ Current-node Localization ↓ Unknown / Conflict Marking

到这里，已经足以处理大多数知识层级、概念关系、研究地图和 Agent / Skill 架构问题。
