# Decision Integration Principle（决策整合原则）

## Definition（定义）

**Decision Integration Principle（决策整合原则）**：
一个知识只有被连接到“何时触发、影响哪个决策、与哪些知识共同作用或冲突、会如何改变选择”时，才真正进入可执行能力系统。

压缩为一句：

> **每学一个知识，都要问：它会在哪个决策节点改变我们的选择？**

## Decision Hook（决策挂钩）

一个最小 Decision Hook 至少包含：

1. **Trigger（触发）**：什么情境下应该调用这条知识；
2. **Decision（决策）**：它影响哪个判断、选择或下一步动作；
3. **Relations（关系）**：它与哪些知识协同、冲突、约束或依赖；
4. **Effect（作用）**：它会如何改变候选方案、证据要求或行动方向。

可选附加：
- Evidence / Confidence（证据 / 置信状态）
- Boundary（适用边界）
- Stop Rule（停止规则）

## Boundary（边界）

它不等于：
- 把知识写进笔记；
- 记住一个定义；
- 在回答中提到一个原则；
- 给生成任务增加更多 checklist。

Declarative Knowledge（陈述性知识）只有在被编译为 Procedural Influence（程序性影响）后，才进入执行系统。

## Relations（关系）

- Learning（学习）产出稳定知识；
- Decision Integration（决策整合）把稳定知识挂到决策节点；
- Decision System（决策系统）在实际任务中按 Trigger 调用知识；
- Feedback（反馈）检验该知识是否真的改善选择，并反向修正知识与挂钩。

## Canonical Loop（规范循环）

```text
Acquire / Learn（获得 / 学习）
→ Understand / Validate（理解 / 验证）
→ Decision Hook（挂接决策）
→ Apply（应用）
→ Observe Feedback（观察反馈）
→ Update Knowledge / Hook（更新知识 / 挂钩）
```
