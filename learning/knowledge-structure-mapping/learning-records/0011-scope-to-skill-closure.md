# 学习收尾目标：从知识输入转向层级构建 Skill

日期：2026-09-23

## 最终目标

建立可复用的 `knowledge-structure-mapping` / 层级构建 Skill，用于判断复杂知识中的：

- Node Type（节点类型）
- Relation Type（关系类型）
- Sibling validity（同级资格）
- Single-axis consistency（单轴一致性）
- Partition claim（划分声明）
- Tree / DAG / Faceted Model / Labeled Graph 的结构选择
- Multiple Parents（多父节点）
- Incomparability（不可比较）
- Current Node localization（当前节点定位）
- Conflict / Unknown marking（冲突 / 未确定关系）

## 收尾条件

当用户已经能够判断大多数常见层级结构与要素关系时，停止继续扩展理论，不追求数学 / 本体论穷尽。

预计剩余核心知识：

1. Partial Order（偏序）：reflexive / antisymmetric / transitive
2. Incomparability（不可比较）
3. Multiple Parents（多父节点）与 Tree / DAG 边界
4. Hasse Diagram thinking（哈斯图思维）：只保留直接上位关系
5. Current-node localization（当前节点定位）
6. Conflict / Unknown handling（冲突 / 未确定处理）

## 归档要求

学习收尾后，将纯知识内容压缩为高浓度 Markdown 参考资料：

- 名词定义精确；
- 区分正式概念、项目工作定义与记忆辅助；
- 只保留可复用知识，不保留教学对话、练习过程、临时类比；
- 作为 Skill 的 reference / supporting material，而不是把全部知识塞进 SKILL.md；
- 按 Matt Pocock 风格：Skill 保留 procedure、trigger、steps、completion criteria；知识细节放 reference；
- Single Source of Truth：正式术语与规则只保留一个权威参考来源，Skill 通过 context pointer 引用。

## 暂不做

- 不继续扩展完整集合论 / 格论 / FCA；
- 不追求本体工程学术穷尽；
- 不把学习对话 HTML 作为 Skill 知识源；
- 不在知识尚未收尾前提前固化 Skill。
