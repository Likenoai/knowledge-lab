# 1. 当前研究已经回答到哪里

经过市场样本、心理学研究与叙事机制拆解，目前可以较有把握地保留：

1. “重生”不是一个单一心理需求题材；
2. 大量商业重生故事首先承担“优势来源合理化”的功能；
3. 重生与系统共享大量优势奖励底盘：
   - 胜任；
   - 能动；
   - 正向结果；
   - 愿望性认同；
4. 重生相对系统最稳定的结构差异是：
   > **存在一条旧时间线。**
5. 旧时间线可能进一步带来：
   - 反事实对照；
   - 旧结果参考点；
   - 因果分支好奇；
   - 特殊的信息分布。

# 5. 当前可用于思考的变量

这次研究真正沉淀下来的不是一句：

> “重生为什么受欢迎。”

而是一组可以反复用于故事判断的变量：

```text
Advantage Source
优势来源

Information Advantage
信息优势

Competence
胜任展示

Agency
能动性

Payoff
收益兑现

Reference Timeline
旧时间线参照

Counterfactual Contrast
反事实对照

Negative Emotional Load
负面情绪负荷

Causal Branch Curiosity
因果分支好奇

Epistemic Configuration
信息结构
```

以后分析一个故事时，可以分别问：

- 主角的优势从哪里来？
- 这个优势是否可信？
- 优势是否真的转化成行动？
- 行动有没有形成可见收益？
- 是否存在参照结果？
- 新结果相对旧结果是否产生放大？
- 观众知道什么？
- 主角知道什么？
- 配角知道什么？
- 好奇心来自“结果未知”还是“干预后世界线未知”？
