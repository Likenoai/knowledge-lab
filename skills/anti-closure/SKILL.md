# Anti-Closure（反闭合）

Use this Skill to expand the search space before further optimizing an already coherent framework.

## Context pointer

Read:
- `../../concepts/anti-closure-loop.md`

When a new external perspective produces claims that may update stable knowledge, use:
- `../truth/SKILL.md` for full validation;
- `../challenge/SKILL.md` for adversarial stress-testing;
- `../judge/SKILL.md` when evidence conflicts.

## Process

### 1. Snapshot the current frame（冻结当前框架快照）

State only the load-bearing structure:
- current core questions;
- major nodes / relations;
- assumptions;
- recurring search terms;
- what the framework currently explains well.

Do not improve it yet.

**Completion criterion:** there is a compact baseline against which genuine novelty can be detected.

### 2. Diagnose closure risk（诊断闭合风险）

Check for:
- repeated local refinement;
- new material being translated immediately into old categories;
- low rate of genuinely new questions;
- confirmation-oriented source selection;
- unexplained recurring failures despite framework completeness.

Classify closure risk: Low / Moderate / High.

**Completion criterion:** explain why external expansion is or is not worth the cost now.

### 3. Select deliberately non-identical external sources（选择非同构外部来源）

Do not search only for support for the current framework.

Prefer 2–5 sources / traditions that differ in at least one of:
- discipline;
- practice environment;
- basic unit of analysis;
- causal assumptions;
- historical period;
- incentives;
- methodology;
- explicit disagreement with the current model.

Possible source types:
- mature books / monographs;
- seminal papers / theories;
- recognized practitioners;
- adjacent disciplines;
- critics / competing schools;
- historical predecessor frameworks.

**Completion criterion:** the selected set is capable of changing the question space, not merely adding evidence to existing answers.

### 4. Extract each source independently（先独立提取，不急着映射）

For each source, preserve its own framing and extract:
- What problem does it think is central?
- What does it treat as the basic unit?
- What variables / mechanisms matter?
- What questions does it ask that we do not?
- What does it assume?
- What training / decision rule follows from it?
- What would it regard as a failure of our current framework?

Do **not** immediately rename everything using current project vocabulary.

**Completion criterion:** each external perspective remains recognizable on its own terms.

### 5. Run novelty mapping（新颖性映射）

Compare the independent briefs against the current framework.

Mark findings as:
- **NEW QUESTION** — we were not asking this;
- **NEW NODE / VARIABLE** — missing construct or state;
- **NEW RELATION** — different causal / structural connection;
- **BOUNDARY** — current rule applies less broadly than assumed;
- **CONFLICT** — incompatible claim or mechanism;
- **DUPLICATE** — already represented;
- **REFRAME** — same facts, different organizing principle.

Prioritize items that would change research direction, evidence requirements, training design, decisions, or output format.

**Completion criterion:** novelty is distinguished from merely new wording or examples.

### 6. Validate before promotion（验证后再升级）

Novelty is not truth.

For material updates:
- use `truth` when a full evidence investigation is needed;
- use `challenge` for counterevidence and alternative explanations;
- preserve UNKNOWN where evidence is insufficient.

Do not promote a book author's experience, metaphor, or successful practice into a universal causal rule without validation.

**Completion criterion:** every promoted change has an explicit epistemic basis.

### 7. Revise minimally but materially（最小但实质地修框架）

Update the framework only when the external perspective changes at least one of:
- what we ask;
- what we observe;
- what evidence we seek;
- how we relate concepts;
- what decision we make;
- what practice we perform.

Avoid adding decorative nodes that do not alter behavior.

**Completion criterion:** the revised framework can state exactly what changed and why.

### 8. Preserve unresolved alternatives（保留未决替代框架）

If multiple frames remain plausible, do not force premature synthesis.

Record:
- competing frames;
- discriminating evidence needed;
- decision implications if each were true.

**Completion criterion:** coherence is not achieved by deleting meaningful disagreement.

## Default output

Return a compact Anti-Closure Report:
1. Current frame snapshot
2. Closure-risk diagnosis
3. External perspectives selected
4. What each perspective sees that the current frame misses
5. Novel questions / nodes / relations / conflicts
6. Validation status
7. Minimal framework changes
8. Remaining alternatives / next external injection

## Boundary

Anti-Closure is not random brainstorming, “find five opinions”, citation accumulation, automatic contrarianism, or replacing the current framework because a famous author said something different.

Its purpose is:

> **expand the search space first, then let evidence and decision value determine what survives.**
