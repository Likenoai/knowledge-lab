# Knowledge Lab

长期知识、研究、认知模型、技能与创作方法的统一知识仓库。

该仓库已经不再限定于 AI 影视。它用于保存跨主题、具有长期复用价值的知识资产，并作为长期知识的 Source of Truth（权威源）。

## Structure

- `concepts/`：核心概念与认知模型
- `research/`：研究资料、证据地图、Canonical Reference（规范参考）
- `skills/`：可执行技能与训练协议
- `learning/`：学习过程与能力训练
- `creative/`：创作相关长期资产
- `components/`：可复用知识组件

## Knowledge Capture

聊天是探究现场，不是最终存档。

当讨论形成可复用 Principle（原则）、Working Model（工作模型）、研究结论、概念边界、Skill（技能）或会改变后续判断的重要结论时，应将其沉淀进本仓库。

详细规则见：

- [Knowledge Capture Policy](KNOWLEDGE_CAPTURE_POLICY.md)
