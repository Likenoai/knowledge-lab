# Question Framing → Decision System Hook

## Source
- Learning workspace: `learning/question-framing/`
- Anchor: `learning/question-framing/ANCHOR.md`
- Canonical principle: `concepts/decision-integration-principle.md`

## Hook

### Name
Question Framing Sufficiency Check（问题定界充分性检查）

### Trigger
当问题中的模糊性、范围、关系类型、证据路径或隐含前提可能改变答案 / 研究 / 决策时触发。

### Decision
当前问题：
- 已达到 Minimum Sufficient Framing（最小充分定界），可以继续；
- 还是仍需澄清一个会改变结果的关键变量。

### Input / Required Context
- 当前目的
- 对话 / 任务情境
- 受众共享上下文
- 风险与可逆性

### Relations
- PRECEDES → Knowledge Acquisition
- CONSTRAINS → Evidence Selection
- CONSTRAINS → Claim Scope
- ENABLES → Research Design
- ENABLES → Decision Analysis

### Effect
若不充分：
- 消除关键 Ambiguity；
- 明确 Construct / Relation / Scope；
- 必要时 Operationalize；
- 明确 Evidence Condition。

若充分：
- 停止继续细分；
- 进入下一决策节点。

### Stop Rule
继续细分若不会实质改变 Answer / Evidence / Decision / Interpretation，则停止。
