# 知识口播项目

## 当前目标

把已经完成学习与验证的知识，转换成可发布的短视频口播内容。

当前优先级高于继续扩建 Decision System。

## 内容定位

不是做“知识搬运”，而是：

> 把复杂的方法论、思维工具和 AI 时代的认知问题，讲成普通人能立刻理解并使用的东西。

核心内容来源优先使用本仓库已经稳定的：
- learning/
- concepts/
- research/

避免为了追热点而脱离已经掌握的知识基础。

## 默认受众

对 AI、学习、思考、决策、知识工作感兴趣的年轻知识工作者与学生。

## 默认视频形态

- 60–90 秒口播为默认长度；
- 一个视频只推进一个主要认知变化；
- 不直接朗读知识结构；
- 先从直觉冲突 / 现实问题切入，再给概念；
- 结尾回到“这对你有什么用”。

## 生产链路

```text
Stable Knowledge（稳定知识）
→ Content Angle（内容角度）
→ Hook（开头冲突 / 反常识）
→ Explanation Path（讲解路径）
→ Spoken Script（口播稿）
→ Record / Publish（录制 / 发布）
→ Audience Feedback（观众反馈）
→ Refine（修正表达与选题）
```

## 选题判断

优先做同时满足以下条件的内容：
1. 有明显认知冲突；
2. 能在 60–90 秒内完成一个认知闭环；
3. 对普通人的学习 / 工作 / AI 使用有直接价值；
4. 底层知识已经足够稳定；
5. 能用具体例子讲，而不是只能抽象解释。

## 当前第一批内容源

Question Framing（问题定界）学习路线：
- 问题不是越精确越好，而是精确到足以支撑目的；
- 关联不等于因果；
- 为什么“为什么 X 会导致 Y”可能已经问错了；
- 好问题必须让现实有机会纠正答案；
- 描述、预测、因果、机制、决策的区别；
- 目标、约束、手段不是一回事；
- 一个问题什么时候已经拆得够细；
- “真正努力的人不会失败”为何无法检验；
- 为什么“AI 会不会让人变笨”本身就是一个坏问题；
- 结果不好，不等于当时的决策一定错。
