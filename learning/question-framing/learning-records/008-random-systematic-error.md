# Learning Record — Random and Systematic Error

## Demonstrated learning
学习者能够区分两类典型测量误差：

- 不同测试时段的环境噪音随机变化，更接近 Random Error；
- 英语能力系统性影响原本想测的物理理解，更接近 Systematic Error。

## Boundary learned
Random / Systematic 的判断取决于误差是否存在稳定结构，而不取决于变量本身的名称。
例如“噪音”如果总是集中出现在某一类学生或某一组条件中，就可能由随机误差转变为系统性偏差来源。

## Current capability floor
已达到 Random Error / Systematic Error 的基础识别层，并能把它们与 Reliability / Validity 联系起来。
