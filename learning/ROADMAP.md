# Learning Roadmap（学习路线图）

> 目的：维护当前“从问题到知识、从知识到能力、表达与行动”的主学习路线。
> 说明：这是项目级操作路线，不声称是学术领域的唯一分类。

## Architecture Update（架构更新）

《The Art of Learning》相关研究暴露出旧路线中的一个混轴：

> Explanation（让人理解） ≠ Mastery Formation（把理解练成能力）

因此当前路线从单一线性链，调整为 Epistemic Loop（求知循环） + Mastery Loop（能力形成循环），再通过表达、决策和现实反馈整合。

### Epistemic Loop（求知循环）

~~~text
Question Framing（问题定界）
→ Knowledge Acquisition（知识获取）
→ Validation / Truth-Seeking（验证 / 求真）
→ Knowledge Structuring（知识结构化）
→ Working Model / Claim（工作模型 / 主张）
~~~

回答：

> 我怎样获得更可靠的理解？

### Mastery Loop（能力形成循环）

仅在任务需要真实执行 / 表现能力时进入：

~~~text
Fundamentals（基本原理）
→ Deliberate Challenge（有意挑战）
→ Error / Loss（错误 / 损失）
→ Diagnostic Feedback（诊断反馈）
→ Refinement（修正）
→ Compression / Internalization（压缩 / 内化）
→ Performance under Disturbance（扰动下表现）
→ Recovery / Reset（恢复 / 重置）
→ Transfer / Self-Expression（迁移 / 个体化表达）
↺
~~~

回答：

> 我怎样把“知道”变成稳定可调用的“会”？

### Integration Layer（整合层）

~~~text
Epistemic Loop
        │
        ▼
Mastery Loop（when needed）
        │
        ▼
Explanation / Teaching（讲解 / 教学）
        │
        ▼
Decision Integration（决策整合）
        │
        ▼
Externalization / Real Feedback（外部化 / 现实反馈）
        │
        └────────────→ update Knowledge / Skill / State
~~~

## Current Status（当前状态）

### 1. Question Framing（问题定界） — DONE at current need
已达到当前需求：
- Topic / Problem / Question / Hypothesis / Claim
- Observation / Interpretation / Frame
- Construct / Scope / Operationalization
- Description / Comparison / Association / Causation / Mechanism / Prediction / Decision
- Ambiguity / Smuggled Assumption / Leading Question / Scope Drift / Untestability / Overbreadth / Overloaded Question
- Evidence Condition
- Minimum Sufficient Framing

后续不再刻意刷题，只在真实任务中调用。

### 2. Knowledge Acquisition（知识获取） — FRAMEWORK EXISTS, needs consolidation
已有：
- Parametric Knowledge（参数化知识） vs External Knowledge（外部知识）
- source routing（来源路由）
- question type → evidence path
- research stop rule（研究停点）

仍需系统收束：
- Claim Decomposition（主张拆解）
- Search / Retrieval Strategy（检索策略）
- Provenance（来源链）
- Source Fitness（来源适配）
- primary / secondary source roles
- when to stop gathering

### 3. Validation / Truth-Seeking（验证 / 求真） — FRAMEWORK EXISTS, needs applied mastery
已有：
- Lenses（多视角）
- Challenge（反证压力测试）
- Judge（证据裁决）
- Truth（完整求真流程）

仍需系统学习 / 应用：
- evidence independence（证据独立性）
- directness / scope match（直接性 / 范围匹配）
- conflicting evidence（冲突证据）
- epistemic status（认知状态）
- uncertainty / calibration（不确定性 / 校准）

### 4. Knowledge Structuring（知识结构化） — TOOLING EXISTS, needs practical integration
已有：
- Node / Relation typing
- Tree / DAG / Faceted Model / Labeled Graph
- Knowledge Structure ≠ Explanation Path

仍需围绕真实知识生产训练：
- 从研究材料抽取概念与关系
- 形成最小但不丢语义的知识地图
- 把“研究结果”压缩成可复用知识资产
- 从局部知识中识别可迁移的 organizing principle（组织原则）

### 5. Mastery / Performance Formation（掌握 / 表现形成） — NEW MAJOR MODULE

这是由《The Art of Learning》映射后补出的关键缺口。

它处理：

> “我已经理解了，但为什么还做不出来 / 做不稳定？”

主要内容：
- Process Before Results（过程先于结果）
- Fundamentals（基本原理）
- Edge / Resistance（能力边缘 / 阻力点）
- Investment in Loss（把错误与失败转化为训练材料）
- Diagnostic Feedback（诊断反馈）
- Making Smaller Circles（从局部深挖、逐步压缩）
- Compression / Internalization（压缩 / 内化）
- Unlearning / Model Revision（去学习 / 模型修正）
- Presence（临在）
- Distraction Tolerance（干扰容忍）
- Stress ↔ Recovery（压力 ↔ 恢复）
- Error Reset / Downward Spiral Prevention（错误重置 / 防止连续失误）
- Trigger / Pre-performance Routine（触发器 / 表现前例程）
- Natural Voice / Personal Adaptation（自然表达 / 个人适配）
- Micro → Macro Transfer（微观原理向宏观迁移）

当前这些内容中，一部分来自 Josh Waitzkin 的经验性框架。涉及普遍因果机制的主张，在升级为项目“已验证规则”前仍需要独立学习科学验证。

参考：
research/learning-science/02_The_Art_of_Learning_框架映射.md

### 6. Explanation / Teaching（讲解 / 教学） — NEXT MAJOR MODULE

旧版“Explanation / Human Learning”拆分后，本模块只处理：

> 怎样让另一个人更容易建立正确心智模型？

主要内容：
- Audience Model（受众模型）
- Entry Point / Hook（入口 / 抓力）
- Explanation Path（讲解路径）
- Cognitive Load（认知负荷）
- Example / Contrast / Counterexample（例子 / 对比 / 反例）
- Concept Naming Timing（术语出现时机）
- Information Density（信息密度）
- Comprehension / Encoding（理解 / 编码）
- 图文、文章、口播等不同媒介的解释压缩

### 7. Decision Integration（决策整合） — STARTED, continues in parallel
已建立：
- Decision Integration Principle
- Decision Hook: Trigger / Decision / Relations / Effect
- Question Framing Hook
- Knowledge Route + Validation Hook

新增要求：
- 当出现“懂但不会”时，先诊断 Knowledge Gap / Practice Gap / Internalization Gap / Performance-State Gap / Personal-Fit Gap；
- 不默认继续补知识；
- 将 Mastery Loop 的训练结果挂回真实 Decision Node。

### 8. Externalization / Feedback（外部化 / 反馈） — INFRASTRUCTURE EXISTS
已有 GitHub SSOT、Skills、Concepts、Research、Learning workspace。

后续重点：
- 发布文章 / 图文 / 视频后的真实受众反馈
- 区分“表达失败”“知识错误”“能力尚未形成”
- 让公开表达反向测试理解与知识结构
- 把失败案例当作可诊断训练材料，而不是只记录成功案例
- 稳定资产进入 Concepts / Skills / Research

## Capability Model（能力模型更新）

旧默认进阶：

~~~text
Understand → Identify → Diagnose → Transfer
~~~

仍适用于大量 Knowledge Task（知识型任务）。

但对于 Performance Task（表现 / 技能型任务），需要继续：

~~~text
Understand
→ Identify
→ Diagnose
→ Guided Transfer
→ Repeated Execution
→ Internalization
→ Performance under Disturbance
→ Adaptive / Personal Expression
~~~

不是所有领域都需要走到最后。

例如：
- 依赖 AI 辅助执行的领域，用户可能只需要稳定达到 Diagnose / Decision；
- 写作、公开表达、谈判、实时判断等核心个人能力，则需要进入 Mastery Loop。

## Remaining Major Learning Blocks（剩余主要学习块）

当前主要还有 5 个大块：

1. Knowledge Acquisition（知识获取）的系统收束；
2. Validation / Truth-Seeking（验证 / 求真）的应用掌握；
3. Knowledge Structuring（知识结构化）的真实材料训练；
4. Mastery / Performance Formation（掌握 / 表现形成）的研究与实践；
5. Explanation / Teaching（讲解 / 教学）的系统学习。

Decision Integration 与 Externalization / Feedback 继续作为贯穿层。

## Application Rule（应用规则）

当前默认应用情境调整为：

> 知识创作者：文章 / 图文优先，视频按内容与生产成本按需扩展。

后续训练案例优先来自真实内容生产：

- 如何把模糊选题改造成可回答的问题；
- 一篇文章中的事实需要什么证据；
- 如何把知识地图转换成读者能连续理解的 Explanation Path；
- 为什么“我知道这个概念”仍然写不出好文章；
- 如何把一次发布失败诊断为知识、表达、练习或状态问题；
- 如何从一个小案例提炼能迁移到其他领域的底层原理。

目标不是只扩知识体系，而是形成：

~~~text
可靠知识
→ 稳定能力
→ 清晰表达
→ 真实发布
→ 现实反馈
→ 下一轮更新
~~~
