# 种子与森林

## 隐喻正文
一颗种子落入森林。种子携带初始的生命结构，却无法仅凭种子判断它最终长成的形态。土壤、水分、光照、邻近树木的竞争与庇护，共同构成生长条件。

根系朝可得水分的方向延伸，枝叶随光照与空间形成不同形态。根越深，便越能触及原本无法获得的资源；树冠越广，也越改变周围的光照与生态关系。

它没有一张完全预定的成长蓝图；最终形态是在既有结构与环境持续互动中形成的。人的发展亦受初始禀赋与条件制约，但人还能够反思目标、作出选择，并以行动改变后续可能性。

> **核心命题**：种子决定不了整片森林，森林也无法独自决定每棵树的形态。对能够反思和选择的人来说，成为自身，同时意味着参与创造自身。

## 映射
| 隐喻对象 | 所指 | 解释范围 |
|---|---|---|
| 种子 | 初始禀赋 | 起点不是完整命运 |
| 土壤、阳光、水分 | 资源、制度、关系、机遇 | 机会与约束 |
| 根系延伸 | 能力积累 | 能力改变资源可及性 |
| 生长方向 | 适应及人的选择（类比） | 路径受条件制约、可调整 |
| 树冠 | 实现的能力与影响 | 成果改变环境 |
| 森林 | 相互依存系统 | 个体发展具有外部性 |

## 能说明什么
1. **反预定论**：禀赋不是结果的完整决定式。
2. **反无限可能论**：可行发展始终受条件约束。
3. **生成性**：发展本身会改变未来的发展条件。
4. **关系性**：主体成长不会独立于环境与他人发生。

## 不能说明什么
- 植物没有人的反思性与道德选择能力；树枝向阳不是自主伦理抉择。
- 自然界存在生长，不代表人有成长的道德义务。
- 更高、更大、更多并不自动代表更善；树木竞争也不能为人的伤害行为背书。
- 隐喻提供理解结构，不构成规范性命题的证据。
