# Knowledge Structure Mapping Resources

## Knowledge

- [本项目：知识结构梳理的形式基础](../../research/structure-mapping/01_知识结构梳理的形式基础.md)
  第一轮研究综合。用于理解 Set Theory、Order Theory、Ontology、Mereology、Facet Analysis 与 Knowledge Graph 在结构梳理中的位置。

- [本项目：结构关系词表与判定规则](../../research/structure-mapping/02_结构关系词表与判定规则.md)
  当前关系判定工作参考。用于 instance-of / is-a / part-of / facet / association 等关系的实际辨别。

- [W3C RDF 1.2 Schema](https://www.w3.org/TR/rdf12-schema/)
  规范性来源。用于 class、instance、`rdf:type`、`rdfs:subClassOf` 和多重 subclass 关系。

- [W3C SKOS Reference](https://www.w3.org/TR/skos-reference/)
  规范性来源。用于 broader / narrower / related，以及层级关系与关联关系的区分。

- [Stanford Encyclopedia of Philosophy: Mereology](https://plato.stanford.edu/entries/mereology/)
  高质量哲学参考。用于 part–whole（部分—整体）关系。

- [Encyclopedia of Mathematics: Partially ordered set](https://encyclopediaofmath.org/wiki/Partially_ordered_set)
  数学参考。用于 partial order（偏序）、可比较性和层级形式结构。

- [Guarino & Welty (2002): Evaluating ontological decisions with OntoClean](https://doi.org/10.1145/503124.503150)
  本体工程研究。用于审查 taxonomy 中不可靠的 is-a / subsumption。

- [Hjørland (2013): Facet analysis](https://doi.org/10.1016/j.ipm.2012.10.001)
  知识组织研究。用于理解单一划分原则与多分面结构。

- [Ganter & Wille: Formal Concept Analysis](https://link.springer.com/book/10.1007/978-3-031-63422-2)
  高阶参考。用于后续 object–attribute relation 和 concept lattice；当前不作为入门必学内容。

## Wisdom / Practice

当前阶段以真实影视研究结构作为练习场，而不是单独寻找外部社区。

优先实践对象：
- Premise Architecture（故事前提架构）的重新梳理；
- Advantage Architecture（优势架构）的变量与层级；
- 整套影视研究体系的节点关系。

## Gaps

- LLM 自动构建 taxonomy / ontology 时的典型错误及评估方法。
