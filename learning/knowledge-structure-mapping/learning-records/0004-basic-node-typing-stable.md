# 能稳定进行基础 Node Typing（节点定型）

用户能够正确将以下节点定型：

- 主角“林凡” → Instance（实例）
- 重生题材 → Class / Concept（类 / 概念）
- Relative Effect → Dimension / Facet（维度 / 分面）
- Advantage → Value（取值），并明确它是 Relative Effect 维度上的具体状态
- Research → Process / Stage（过程 / 阶段）
- CAUSES → Relation（关系）

这表明用户已经能够区分具体对象、一般概念、维度、取值、流程阶段和关系。下一步训练重点不再是基础定义，而是混淆案例：同一个词如何因建模目的改变 Node Type，以及如何识别“伪同级”。
