# Learning Record — Comparative Question

## Demonstrated learning
学习者能够正确判断：
- “男生和女生过去一年平均阅读时间是否不同？” = Comparative（比较） + Descriptive（描述）；
- “每周阅读时间越长的学生，语文成绩是否越高？” = Association（关联）；
- “如果把学生每周阅读时间从 2 小时提高到 5 小时，语文成绩是否会提高？” = Causal（因果）。

## Current capability floor
学习者已经理解 Comparative 不是必须与其他问题类型互斥的独立盒子，而可以描述问题的比较结构，并与 Descriptive / Causal 等推断目标叠加。
