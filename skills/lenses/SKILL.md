# Lenses

Run independent perspective analysis before synthesis.

## Context pointer

Read:

- `../../concepts/five-lens-truth-seeking.md`

## Process

### 1. Frame the target

State the question or claim being examined and the scope that matters.

**Completion criterion:** every lens is examining the same target rather than adjacent questions.

### 2. Run the fixed five lenses independently

For each lens, produce:
- the questions this lens uniquely raises;
- the most plausible explanation from this lens;
- evidence or source types that would test it;
- boundary conditions or unknowns.

Keep each lens independent before seeing the final synthesis.

**Completion criterion:** all five lenses contribute at least one non-duplicative question or finding, or are explicitly marked low-yield for this topic.

### 3. Add dynamic specialists when needed

Add only specialists required to resolve domain-specific mechanisms the fixed five cannot competently judge.

**Completion criterion:** every unresolved technical mechanism has either an appropriate specialist lens or an explicit UNKNOWN.

### 4. Return perspective briefs

Keep agreement and disagreement visible. Do not merge conclusions yet.

## Output

Return:
- Target;
- five perspective briefs;
- optional specialist briefs;
- emerging agreements;
- conflicts / unknowns.

## Boundary

Lenses expands and investigates the question space. It does not decide which conclusion is true and does not resolve conflicts by voting.
