# Concepts

这里保存项目级、可跨任务复用的 **Canonical Concepts（规范概念）**。

它不同于：
- `research/`：保存研究过程、证据与展开论证；
- `learning/<topic>/GLOSSARY.md`：保存某个学习工作区中用户已经掌握的词汇；
- `skills/`：保存“遇到某类任务时怎么做”的执行过程。

## Promotion Rule（进入概念库的条件）

一个概念只有在以下条件基本满足时才进入这里：

1. **Name**：有稳定、可复用的名称；
2. **Definition**：可以用一句或一小段准确界定；
3. **Boundary**：知道它不是什么，或与邻近概念如何区分；
4. **Relations**：能说明它与关键相关概念的关系；
5. **Reuse**：预计会跨任务反复使用。

这里不是聊天摘录库，也不保存尚未收束的临时说法。

## Single Source of Truth

当某个 Skill 需要一个概念定义时，优先指向这里，而不是把同一套定义复制进多个 Skill。
