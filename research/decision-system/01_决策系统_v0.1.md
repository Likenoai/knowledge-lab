# Decision System v0.1（决策系统 v0.1）

> 状态：Working Architecture（工作架构）
> 目的：把“知道什么”转换为“在什么时刻改变什么选择”。

## 1. Modeling Purpose（建模目的）

这个系统不试图保存所有知识。

它只回答：

> **面对当前状态，下一步有哪些真正需要做选择的节点；哪些知识应该在这些节点被触发；知识如何改变下一步。**

因此结构采用 **Labeled Graph（带标签关系图）**，而不是固定线性 checklist。

---

## 2. Core Nodes（核心节点）

### State（状态）
当前可观察或已知的世界状态、任务状态、故事状态、学习状态。

### Decision Node（决策节点）
存在多个合理候选行动 / 解释 / 路径，且不同选择会影响后续状态的位置。

### Knowledge Hook（知识挂钩）
把知识连接到某个 Decision Node 的执行接口。

### Action / Inference（行动 / 推断）
在当前证据和目标下实际采取的选择。

### Feedback（反馈）
行动后的新证据、结果、失败、偏差或新约束。

---

## 3. Core Loop（核心循环）

```text
State_n（当前状态）
→ Detect Decision Node（识别决策节点）
→ Retrieve Relevant Hooks（提取相关知识挂钩）
→ Compare / Judge Options（比较 / 裁决候选）
→ Action / Inference（行动 / 推断）
→ Outcome / Evidence（结果 / 证据）
→ Feedback（反馈）
→ State_n+1（新状态）
```

这与滚动式创作结构同构，但适用于研究、学习、产品和故事。

---

## 4. Decision Hook Schema（决策挂钩结构）

每条稳定知识若要进入系统，至少回答：

```text
Trigger:
Decision:
Relations:
Effect:
```

推荐增强结构：

```text
Name:
Trigger:
Decision:
Input / Required Context:
Relations:
Effect:
Evidence / Confidence:
Boundary:
Stop Rule:
```

---

## 5. First Integrated Hook — Question Framing（第一个已整合挂钩）

### Trigger（触发）

当出现以下任一情况时触发 Question Framing：

- 关键词可能存在 Ambiguity（歧义）；
- 不同合理解释会导向不同答案；
- Relation（关系类型）不清楚；
- Scope（范围）会改变结论适用性；
- 因果 / 机制 / 决策主张需要不同证据路径；
- 问题带有 Smuggled Assumption（偷带前提）或 Leading Wording（诱导措辞）；
- 证据搜集方向无法确定；
- 当前任务风险较高或结论不可轻易撤回。

### Decision（决策）

决定：

> **当前问题是否已经精确到足以进入回答 / 搜索 / 研究 / 决策，还是仍需要继续定界？**

### Relations（关系）

- PRECEDES → Knowledge Acquisition（知识获取）
- CONSTRAINS → Evidence Selection（证据选择）
- CONSTRAINS → Claim Scope（主张范围）
- ENABLES → Validation（验证）
- ENABLES → Decision Analysis（决策分析）

### Effect（作用）

若触发，则按需检查：

```text
Purpose（目的）
→ Construct（构念）
→ Relation（关系）
→ Scope（范围）
→ Operationalization（操作化）
→ Evidence Condition（证据条件）
→ Stop（停止）
```

不是每次机械执行完整链路，只处理会改变当前任务的部分。

### Stop Rule（停止规则）

采用 **Minimum Sufficient Framing（最小充分定界）**：

如果继续拆解已经不太可能实质改变：
- Answer（答案）
- Evidence（证据选择）
- Decision（决策）
- Interpretation（双方理解）

且进一步拆解的边际收益低于沟通 / 时间 / 认知成本，则停止。

## 7. Rule for Future Learning（未来学习接入规则）

以后完成一个稳定学习单元后，不默认只写入 Glossary。

若该知识具有实际决策价值，再补一条：

> **它在哪个 Decision Node 被触发，它如何改变选择？**

只有能够回答这个问题的知识，才视为真正进入 Decision System。
