# Learning Roadmap（学习路线图）

> 目的：维护当前“从问题到知识、从知识到表达与行动”的主学习路线。
> 说明：这是项目级操作路线，不声称是学术领域的唯一分类。

## Overall Loop（整体闭环）

```text
Question Framing（问题定界）
→ Knowledge Acquisition（知识获取）
→ Validation / Truth-Seeking（验证 / 求真）
→ Knowledge Structuring（知识结构化）
→ Explanation / Human Learning（讲解 / 人类学习）
→ Decision Integration（决策整合）
→ Externalization / Feedback（外部化 / 反馈）
↺
```

- 60–90 秒口播的信息压缩与闭环

## Remaining Major Learning Blocks（剩余主要学习块）

若按“需要继续系统学习的新内容”计算，后面主要还有 **4 个大块**：

1. Knowledge Acquisition（知识获取）的系统收束；
2. Validation / Truth-Seeking（验证 / 求真）的应用掌握；
3. Knowledge Structuring（知识结构化）的真实材料训练；
4. Explanation / Human Learning（讲解 / 人类学习），并以知识博主口播为主场景。

Decision Integration 与 Externalization / Feedback 不作为一次学完的独立课程，而是贯穿后续所有模块的持续整合层。

## Application Rule（应用规则）

从现在开始，后续训练案例默认优先使用：

> **知识博主 / 口播内容生产**

例如：
- 如何把模糊选题改造成可回答的问题；
- 一条口播中的事实需要什么证据；
- 如何判断一个“反常识观点”是不是偷带前提；
- 如何把知识地图转换成 60–90 秒 Explanation Path；
- 观众评论反对时，如何判断是表达问题、证据问题还是 Frame 不同。

目标不是暂停知识体系扩建，而是让扩建过程始终落在真实应用上。
