# Mission: Knowledge Structure Mapping（知识结构梳理）

## Why

真正理解并掌握知识结构梳理，使自己在影视研究、复杂问题分析和未来 Agent / Skill 设计中，能够识别概念之间真正的关系，而不是凭直觉把内容塞进一棵树。

最终还要把经过学习和实践验证的方法沉淀为 `knowledge-structure-mapping` Skill。

## Success looks like

- 能区分 instance-of、is-a、part-of、facet/value、sequence、causal、associative 等主要关系。
- 能发现“伪同级”：判断一组并列节点是否混用了不同分类轴。
- 能判断一个知识结构应该使用 Tree、DAG、Faceted Model 还是 Labeled Graph。
- 能对影视研究中的复杂知识结构进行定位：当前节点、父节点、同轴节点、正交维度、上下游关系。
- 面对陌生领域时，也能使用同一套结构判断方法，而不是依赖影视领域经验。
- 在充分理解和实践后，将稳定 Procedure 沉淀为 `knowledge-structure-mapping` Skill。

## Constraints

- 目标优先是 Understand → Identify → Diagnose → Transfer，不要求一开始掌握完整形式数学证明。
- 数学知识按实际结构问题逐步引入，不从完整集合论教材线性学习。
- 每次教学保持一个紧凑节点，避免同时扩展太多新概念。
- 科学或形式化结论优先使用可靠来源，不把工作模型误写成既定事实。

## Out of scope

- 暂不系统学习完整数理逻辑、抽象代数或范畴论。
- 暂不实现自动 ontology / taxonomy 构建算法。
- 暂不把 Knowledge Structure Mapping 与 Gentner 的 Structure-Mapping Theory（类比结构映射理论）混为一谈。
