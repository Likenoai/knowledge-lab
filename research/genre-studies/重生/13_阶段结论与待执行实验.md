因此当前研究重新打开。

# 3. 初步补检索已经发现的新证据

这一步证明此前不应过早停止。

### 3.1 Fresh Start Effect

已有多项现场数据和实验支持：

> 时间地标会把过去与现在分成不同心理时期，并能把“过去不完美的自己”心理上隔离出去，从而增强目标启动。

这与重生的：

```text
旧人生
→ 新时间起点
→ “以前的我”与“现在的我”分离
```

存在明显结构同构。

但：

> 现实中新年 / 搬家产生 fresh-start effect

不能直接推出：

> 观看重生故事会产生同样效果。

当前状态：

**[迁移性推断]**

---

### 3.2 Redemptive Story Preference

美国成年人六个样本、两项研究（总 N=1872）中，负面经历获得积极解决的 redemptive stories 被稳定评价得比负面结局故事更积极、更可取，叙述者也被评价得更好。

这比之前仅研究“人生故事与幸福感相关”更接近：

> **故事结构偏好本身。**

但研究：

- 样本主要为美国成年人；
- 材料是创伤人生故事；
- 并非娱乐短剧；
- 不是“重来一次”结构。

当前状态：

**[直接叙事偏好证据，但外推受文化与题材限制]**

---

### 3.3 Fiction as Alternative Lives

2025 年一项 N=498 的阅读研究直接考察：

> 人是否使用小说来满足“体验其他人生 / alternative identities”的愿望。

结果显示，有较强 “sense of possibility” 的读者更容易报告对未实现人生的向往；其中一部分人自发表示阅读小说能够通过承担替代身份满足这种向往。

这给：

> “重生可能提供替代人生 / 再活一次的代理体验”

提供了比此前更直接的桥梁证据。

当前状态：

**[较强相关桥梁证据，仍非重生题材因果实验]**

---

### 3.4 Storyworld Possible Selves

2023 年 N=543 的研究发现，读者报告的 transformative reading experiences 会激活：

- present-self；
- desired possible self；
- past-self；
- feared possible self；

等不同时间维度的“故事世界可能自我”。

其中 desired possible self 的出现频率仅次于 present self；情绪投入和 narrative transportation 与这些 possible-self 激活呈正相关。

当前状态：

**[媒体/叙事桥梁证据]**

---

### 3.5 Self-Expansion through Fictional Characters

两项研究发现：

> 当虚构人物更接近读者的 ideal self-guide 时，更容易与 perceived self-expansion 联系；transportation 也与 self-expansion 有关。

这意味着重生主角的：

- 更强能力；
- 更好人生；
- 更高掌控；
- 更成功版本；

除了 “wishful identification” 外，还可以从：

> **ideal-self / self-expansion**

角度继续理解。

当前状态：

**[媒体心理学支持，重生特异性未验证]**

---

### 3.6 TEBOTS

TEBOTS 理论与后续实验研究提出：

> 现实自我受到身份、能力、社会角色和自我调节压力限制时，故事可以暂时扩展 self boundaries。

已有研究中：

- self-affirmation 降低自我维护压力时，narrative engagement 会下降；
- pandemic identity threat 与 boundary expansion、transportation、appreciation 有关系；
- 部分实验和准实验支持“自我压力 / 威胁 → 更强故事投入”的方向。

这一步尤其重要，因为它已经开始连接：

```text
稳定心理机制
↓
现实群体状态
↓
叙事需求
```

当前状态：

**[有实验支持的桥梁机制]**

# 4. 对原有重生模型的修正

现在不能只用：

```text
重生
→ 开挂合理化
→ 优势兑现
```

也不能只用：

```text
重生
→ 反事实修复
```

更完整的候选模型变成：

```text
重生

├─ Advantage Architecture
│  └─ 信息 / 经验 / 能力优势
│
├─ Reference Timeline
│  └─ 旧结果参照 / 反事实对照
│
├─ Fresh Start
│  └─ 与旧自我分离 / 新开始
│
├─ Possible Self
│  └─ “另一种我 / 更好的我”
│
├─ Redemption
│  └─ 失败过去 → 改善未来
│
└─ Self-Expansion
   └─ 暂时超出现实身份与能力边界
```

其中哪些是重生真正特有、哪些只是叙事普遍机制，仍需要继续区分。
