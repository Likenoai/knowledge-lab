## 2. Cognitive Integration 的两项系统性质

当前保留：

1. Reciprocal Coordination（互惠协调）
   - 一个组件的认知结果改变共享状态；
   - 新共享状态反过来改变其他组件下一轮认知处理；
   - 重点不是“互相聊天”，而是跨组件持续相互更新。

2. Constitutive Complementarity（构成性互补）
   - Human 与 AI 承担不同而真实的认知变换；
   - 整体认知功能由多个不同组件共同实现；
   - 外部组件不是单纯信息源，而是认知过程中的功能组成。

重要修正：

> Cognitive Integration 更适合被理解为 Human–AI 运行架构达到一定耦合程度后表现出的系统性质，而不是一个与运行机制并列的独立模块。

## 3. Shared Cognitive State

当前稳定模型：

Shared Cognitive State
= Objective State
+ Epistemic State
+ Commitment State

对应：

- Objective State（目标状态）：我们想要什么？
- Epistemic State（认识状态）：我们认为现实怎样？
- Commitment State（承诺状态）：我们已经决定做什么？

航海比喻：

- Objective = 目的地
- Epistemic = 海图 / 对当前海况与位置的认识
- Commitment = 已选航线

关键结论：

- Memory 是状态持久化 / 重建基础设施，不是 State 本身；
- Uncertainty 是 Epistemic State 的属性；
- Evidence 是 Epistemic State 的依据 / provenance；
- Question 可被理解为 Objective 与 Epistemic 之间的 gap；
- Plan 是 Commitment 的执行结构。

## 4. 第二层运行架构的重构

早期曾使用：

Shared Cognitive State
+ Complementary Transformation
+ Corrective Feedback

后经对抗性检验，发现该三分结构存在层级混杂。

当前更认可的可实现架构：

1. Shared Cognitive State（共享认知状态）
2. Control Policy（控制策略）
3. Cognitive Operators（认知算子）
4. State Update Rules（状态更新规则）

Feedback 不再被视为同级“模块”，而是：

> 输出 / 行动的现实后果或证据重新进入 Update，从而形成闭环的关系。

更抽象地：

Cognitive System
= State
+ Transition
+ Feedback

其中：

Transition = Policy + Operator

## 5. Cognitive Loop

当前最简循环：

S_t
→ Policy
→ Operator
→ Candidate Result
→ Evidence / Reality
→ Update
→ S_t+1

符号解释：

- S_t：当前 Shared Cognitive State
- π：Control Policy
- O_t：当前被选择的 Cognitive Operator
- R_t：当前 operator 产生的 Candidate Result（候选结果）
- E_t：现实 / 证据 / observation
- S_t+1：更新后的下一轮 Shared Cognitive State

核心区别：

> R_t 是“产生了什么候选结果”，不等于结果已经被写入下一轮状态。

当前可写为：

O_t = π(S_t)

R_t = O_t(S_t)

S_t+1 = U(S_t, R_t, E_t)

中文压缩：

> 状态 → 选择 → 操作 → 结果 → 证据 → 更新

或：

> 存 → 选 → 做 → 验 → 改

## 6. State Update Rules

三种状态需要不同的更新规则：

### Epistemic State
Evidence-responsive
- 根据证据更新；
- 新输入不自动成为信念。

### Objective State
Value / Agency-responsive
- 事实可以改变目标的事实前提；
- 但不能仅凭外部事实自动决定“什么值得追求”。

### Commitment State
Default Persistence + Triggered Reconsideration
- 默认保持；
- 只有支撑 Commitment 的依据发生实质变化并越过重新审议阈值时，才重新打开。

Commitment 的两个主要失效来源：

1. Objective Shift（目标变化）
2. Epistemic Defeat / Decision Basis Invalidated（认识依据失效）

## 7. Control Policy

当前进入但尚未研究完成的主题：

> Control Policy 到底依据什么选择下一步 Cognitive Operator？

当前工作命题：

> 在允许的 Cognitive Operators 中，根据当前 Shared Cognitive State，优先选择 Expected Marginal Cognitive Value（预期边际认知价值）最高的下一步操作。

直觉表达：

> 下一步不做“最聪明的事”，而做“现在最值的认知动作”。

候选近似：

Expected Marginal Cognitive Value
≈ Expected Improvement
- Cognitive / Resource Cost

典型 operator 包括：

- Search / Retrieve
- Compare
- Structure / Synthesize
- Critique / Counterexample
- Simulate / Predict
- Deliberate / Decide
- Act
- Stop

重要边界：

- Boundary / Constraint 决定哪些 operator / actor allocation 不允许；
- Control Policy 在允许集合内选择当前最值得做的下一步；
- Human / AI 的 operator 可以写为 <Actor, Cognitive Transformation>。

## 8. 与 Cognitive Integration 的关系

当前因果关系更准确地表示为：

Shared State
→ Policy
→ Human / AI Operators
→ Result
→ Evidence
→ Update
→ Shared State
↺

运行后：

- 不同 Human / AI operator 被合理调用并组合
  → Constitutive Complementarity

- 一个组件输出经状态更新影响另一个组件下一轮处理
  → Reciprocal Coordination

因此：

> 第二层运行机制是实现结构；
> Cognitive Integration 是该结构运行后出现的系统性质。
