# MISSION

## Topic
Question Framing（问题定界 / 研究问题构造）

## Why this matters
把模糊兴趣、直觉或观点转化为可被知识与证据真正回答的问题，是后续 Knowledge Acquisition、Validation、Research 与 Decision 的入口能力。

## Target capability
完成本学习轨后，学习者应能：

1. 区分 Topic、Problem、Question、Hypothesis、Claim；
2. 识别一个问题的 Object、Relation、Scope、Operationalization 与 Testability；
3. 判断问题属于描述、比较、关联、因果、机制、预测还是决策；
4. 发现 leading question、概念模糊、范围漂移、不可检验、偷带前提等问题；
5. 把模糊问题重构成可研究、可证伪、可选择证据的问题；
6. 根据问题类型判断后续应寻找何种证据与研究设计。

## Mastery standard
达到以下能力才视为掌握：

- Understand：能准确解释核心概念及其边界；
- Identify：能在陌生案例中识别问题结构与缺陷；
- Diagnose：能说明“哪里错、为什么错、会造成什么后果”；
- Transfer：能把真实业务 / 学习问题重构成更好的问题，并说明什么证据会改变答案。

最终目标不是背框架，而是形成稳定的 Question Framing 判断能力。

- 学习者已具备 Understand / Identify / Diagnose，并能在真实问题中进行初步 Transfer。
