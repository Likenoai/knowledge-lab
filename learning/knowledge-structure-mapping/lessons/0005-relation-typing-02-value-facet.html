Knowledge Structure Mapping · Relation Typing 02

VALUE_OF 与 FACET_OF

这一单元只增加两个关系：一个连接“取值 ↔ 维度”，一个连接“维度 ↔ 被描述的整体模型”。

1. VALUE_OF（是某维度的取值）

测试：A 是不是 B 这个 Dimension（维度）上的一个 Value（取值）？

Advantage → VALUE_OF → Relative Effect High Cost → VALUE_OF → Cost

2. FACET_OF / DIMENSION_OF（是某模型的一个维度 / 分面）

测试：A 是不是用来描述 B 的一个独立观察轴？

Cost → FACET_OF → Advantage Architecture Relative Effect → FACET_OF → Premise Architecture

3. 最关键的链

High Cost → VALUE_OF → Cost → FACET_OF → Advantage Architecture

三层角色分别是：

Value（取值） → Dimension（维度） → Model / Concept（被描述的整体模型）

4. 为什么不能都画成父子？

节点 A关系节点 B语义
High CostVALUE_OFCost取值属于某个维度
CostFACET_OFAdvantage Architecture维度属于一个模型的描述轴

如果无标签地画成：

Advantage Architecture └─ Cost └─ High Cost

视觉上虽然像层级，但两条边的语义完全不同。

5. 第一轮练习

D. Cost —— ? —— Advantage Architecture
