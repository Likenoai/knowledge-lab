# Learning Record — Frame Priority

## Demonstrated learning
在“用户创建了剧本项目，但大量用户进入分镜工作台后 2 分钟内退出”的案例中，学习者正确识别：

- “用户不喜欢 AI”是三个候选 Frame 中较差的研究入口；
- 已开始使用 Fit / Discriminability / Decision Leverage 三个标准进行判断。

## Refinement needed
- Fit：创建项目只能说明存在一定使用意愿或尝试意愿，不能完全推出“用户喜欢 AI”或排除抵触。
- Discriminability：需要判断该 Frame 是否能导出与其他 Frame 不同的可观察预测，而不只是说它“不主要”。
- Decision Leverage：即使“用户不喜欢 AI”过于宽泛，如果被可靠证实，仍可能影响定位、受众筛选、预期管理等决策，因此不是零杠杆。

## Current capability floor
已进入 Frame 质量 Diagnose 初级阶段：能识别较弱 Frame，但对三项标准的精确定义还需要进一步训练。
