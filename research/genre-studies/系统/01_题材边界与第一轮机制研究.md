# ◆ 1. Reality Check｜“系统流”实际是什么

现有网络文学研究与批评材料支持一个相对稳定的现实描述：

> “系统流”并不是一个边界封闭、只能独立存在的题材，更接近一种可嵌入都市、玄幻、修仙、职业、言情等类型的 premise device（前提装置）/ rule device（规则装置）。

中国作家网对系统流的描述包括：

- 主角脑中存在独立的信息化程序；
- 系统帮助宿主获得资源或技能；
- 等级、经验值、任务、装备等明显借鉴网络游戏；
- 叙事常围绕逐步升级与系统规则展开；
- 该结构可与玄幻、修仙、都市、言情、穿越、重生等组合。

来源：
https://image.chinawriter.com.cn/n1/2024/1212/c404027-40380692.html

人民网刊载的雷宁研究进一步提出：

> 系统流中的“系统”常被简化为“一组规则，必要时加上数值”，并通过规则与既有类型叙事建立新的关联；系统能把抽象的“变强”转换成具体指标与数字增长。

来源：
https://ent.people.com.cn/n1/2025/1011/c1012-40579825.html

2023 年石河子大学硕士论文《网络系统流小说的叙事研究》也把系统同时描述为：
- 游戏世界系统；
- “金手指”功能；
并指出常见叙事特征包括数值化、完整设定、系统视角及任务 / 升级等。

来源：
https://lwtj.shzu.edu.cn/docinfo.action?id1=88ba998224a67a548358f0d0bf760979&id2=OsSPeNOj%252BQo%253D

### 当前现实判断

[已验证作品 / 文学研究事实]

“系统”至少稳定包含以下候选结构：

```text
System
├─ Rule（规则）
├─ State Information（状态信息）
├─ Goal / Task（目标 / 任务，非所有系统都必须）
├─ Feedback（反馈）
├─ Reward / Penalty（奖励 / 惩罚，常见但非必要）
├─ Progress Representation（进度 / 数值表示，常见）
└─ Capability / Resource Change（能力 / 资源改变，常见）
```

重要边界：

> “任务—奖励—升级”是高频系统形态，但不应在研究开始时被定义为所有系统叙事的必要条件。

# ◆ 2. 第一轮结构拆解：系统真正“增加”了什么

与“主角突然得到一个强能力”相比，系统不只是给予资源。

更一般的候选变化是：

## 2.1 Externalized Rule Layer｜外显规则层

系统把世界中原本：
- 隐含；
- 模糊；
- 需要角色自行发现；

的规则，部分外显为：

```text
条件
→ 行为
→ 反馈
→ 后果
```

[作品结构事实 + 工作抽象]

这可能是系统题材最值得优先研究的独立变量。

---

## 2.2 State Legibility｜状态可读性

系统常把抽象状态转成可读信息：

```text
能力 → 等级 / 数值
关系 → 好感度
目标 → 任务状态
成长 → 经验值 / 解锁
风险 → 倒计时 / 惩罚提示
```

这里的核心不是“数字”本身，而是：

> 原本不可直接观察的状态被系统化地显示出来。

暂定工作概念：

**State Legibility（状态可读性）**

[项目工作概念]

---

## 2.3 Goal Externalization｜目标外显

系统可以直接把一个模糊处境转换成明确目标：

```text
复杂世界
→ 系统判定
→ 任务
→ 明确完成条件
```

它可能降低“下一步应该做什么”的不确定性。

这不是所有系统必须具备的特征，但在任务型系统中非常核心。

---

## 2.4 Contingent Feedback｜条件性反馈

系统通常建立稳定映射：

```text
做 X
→ 系统判定
→ 得到 Y
```

于是行动与反馈之间的 contingency（条件对应关系）更加显式。

这比“奖励”本身更一般。

---

## 2.5 Capability Mediation｜能力中介

主角的能力 / 资源变化不必完全来自传统世界内因果：

```text
现实 / 世界规则
→ 系统中介
→ 获得技能 / 道具 / 资源 / 信息
```

系统因此可以成为：

> character ↔ world 之间额外的一层 causal interface（因果接口）。

[工作假设]

# ◆ 3. Competing Hypotheses｜系统价值的竞争解释

当前不能只用“系统就是爽文外挂”解释。

至少存在以下竞争解释。

## H1｜Advantage Granting Hypothesis

系统主要价值：
> 给主角能力、资源、信息优势。

如果该解释占主导，那么“无任务、无进度显示、只提供能力”的系统也应保留大部分价值。

状态：
[工作假设]

---

## H2｜Goal Clarification Hypothesis

系统的重要价值：
> 把复杂情境拆成明确目标 / 子目标，减少目标模糊性。

对应语义邻域：
- Goal-setting Theory
- goal specificity
- guided paths
- task decomposition

状态：
[迁移性推断候选]

---

## H3｜Progress Visibility Hypothesis

系统的重要价值：
> 让角色的成长与进展持续可观察。

对应：
- progress monitoring
- performance feedback
- self-efficacy / competence
- progress bars / levels

状态：
[迁移性推断候选]

---

## H4｜Rule Legibility / Predictability Hypothesis

系统的重要价值：
> 把原本模糊的世界因果转成更明确的规则—反馈关系，提高可预测性与可计算性。

对应：
- gamification
- information systems
- feedback loops
- perceived control

当前状态：
[文献检索未完成]

---

## H5｜Reward Reinforcement Hypothesis

系统的重要价值：
> 任务与奖励形成持续 reinforcement（强化），使进展本身成为重复性的动机结构。

但该解释不能简单等同于“奖励越多越好”。

状态：
[迁移性推断 + 重要反证存在]

---

## H6｜Game-schema Familiarity Hypothesis

系统借用玩家熟悉的：
- 任务；
- 等级；
- 属性；
- 奖励；
- 解锁；

让读者以既有游戏 schema（图式）快速理解故事规则。

文学研究支持系统流与网络游戏经验有明确历史与结构联系，但“熟悉 schema 是否直接增强叙事偏好”仍需继续检索。

状态：
[结构事实 + 心理机制未完成]

# ◆ 4. 第一轮科学映射

## 4.1 Goal Setting｜明确目标

Locke & Latham 对数十年 Goal-setting Theory 研究的总结指出：

- specific goals（具体目标）通常比模糊的“尽力而为”目标更能引导行为；
- 目标影响 attention、effort、persistence 与 task strategy；
- feedback 是目标有效运作的重要边界条件。

来源：
Locke & Latham (2002)
https://pubmed.ncbi.nlm.nih.gov/12237980/

Locke & Latham (2006)
https://www.psychologicalscience.org/journals/current-directions/j.1467-8721.2006.00449.x/

### 对系统的迁移

```text
模糊欲望
→ 系统任务
→ 明确目标
→ 明确完成条件
```

可能把“角色想变强”转成可执行目标。

当前证据状态：

[迁移性推断]

因为这些研究研究人的真实目标追求，不是观看系统题材的受众体验。

---

## 4.2 Progress Monitoring｜进度监控

Harkin et al. (2016) 对 138 项研究、N=19,951 的 meta-analysis 发现：

> 促进 goal progress monitoring 的干预不仅显著提高进度监控频率，也提高 goal attainment；平均 goal attainment 效应约 d = 0.40。

来源：
https://pubmed.ncbi.nlm.nih.gov/26479070/

### 对系统的迁移

系统常持续显示：

- 经验值；
- 等级；
- 任务完成度；
- 技能熟练度；
- 解锁状态。

这说明“progress legibility（进度可读性）”具有成熟的行为科学对应机制。

但：

> 现实中监控自己的目标进度有效
≠
观看别人拥有进度条一定更好看。

因此：

[已验证基础机制]
+
[迁移性推断到叙事]

## 4.3 Gamification Theory｜规则、目标、反馈、可管理任务

Krath et al. 的 systematic review 对 gamification / serious games / game-based learning 的理论基础进行整合，指出研究中反复出现的基本原则包括：

- 明确目标及其相关性；
- 通过 guided paths（引导路径）推动行动；
- immediate feedback（即时反馈）；
- reinforcement（强化）；
- 把复杂内容拆成 manageable tasks（可管理任务）；
- 提供不同 progress paths；
- 根据能力调整复杂度。

来源：
https://doi.org/10.1016/j.chb.2021.106963

### 对系统题材的意义

它提供了一个比“系统=外挂”更丰富的候选解释：

```text
System
→ Goal Legibility
→ Path Guidance
→ Immediate Feedback
→ Progress Visibility
→ Reinforcement
```

[成熟相邻领域证据]
+

## 4.4 Competence / Positive Feedback｜胜任与正反馈

Deci, Koestner & Ryan (1999) 对 128 项实验的 meta-analysis 发现：

- positive feedback 提高 free-choice behavior 与 self-reported interest；
- 但 expected tangible rewards、engagement-contingent / completion-contingent / performance-contingent rewards 在不少条件下反而削弱 intrinsic motivation。

来源：
https://pubmed.ncbi.nlm.nih.gov/10589297/

### 重要修正

系统题材不能简单建模为：

```text
奖励
→ 越多越爽
→ 越有吸引力
```

更合理的候选区分是：

```text
Informational Feedback
告诉你“做得怎么样 / 进步了多少”

vs

Controlling Reward
“为了奖励所以做”
```

二者的心理效果并不相同。

当前状态：

[已验证基础机制]
+
[叙事迁移未验证]

---

## 4.5 Reward Uncertainty｜不确定奖励

Shen, Fishbach & Hsee 的实验研究发现，在特定“关注追求过程”的条件下，不确定奖励可能让人投入更多资源，即 motivating-uncertainty effect。

来源：
https://research.cuhk.edu.hk/en/publications/the-motivating-uncertainty-effect-uncertainty-increases-resource--2/

这为系统中的：
- 随机宝箱；
- 未知奖励；
- 抽取；
- 随机技能；

提供相邻行为研究。

但它显然不是所有系统题材的核心结构。

当前状态：
[相邻直接实验]
+
[题材特异性弱]

# ◆ 5. 第一轮最重要的新发现

目前最值得保留的不是“系统给主角开挂”。

而是系统可能同时改变三个更基础的东西：

```text
World / Action
原本模糊、连续、隐性
        ↓
System Interface
        ↓
Rule Legibility      规则变得可读
Goal Legibility      目标变得可读
Progress Legibility  进展变得可读
```

暂时可以把它们合称为：

## Legibility Architecture｜可读性架构

> **这是本项目当前新提出的工作概念，不是现成学术术语。**

系统可能把：
- 隐性规则；
- 模糊目标；
- 连续成长；
- 不可见能力；

转换成显式、离散、可追踪的信息。

这与单纯 Advantage Architecture 不同。

例如一个系统甚至可以：

> 不给主角明显能力优势，只负责显示规则、任务与状态。

如果这样的故事仍然保留强烈“系统感”，说明“系统=优势来源”不是充分定义。

# ◆ 6. 第一轮结构模型

当前候选模型：

```text
SYSTEM PREMISE
        │
        ├─ Rule Externalization
        │  隐含规则 → 显式规则
        │
        ├─ State Legibility
        │  隐含状态 → 可读状态
        │
        ├─ Goal Externalization
        │  模糊目标 → 明确任务
        │
        ├─ Contingent Feedback
        │  行动 → 判定 → 反馈
        │
        ├─ Progress Representation
        │  连续变化 → 等级 / 数值 / 解锁
        │
        └─ Capability Mediation
           系统 → 信息 / 技能 / 资源
```

其中：

- Capability Mediation 更接近 Advantage Architecture；
- 前五项提示“系统”可能还有一个独立于优势的 **Legibility / Rule Interface** 维度。

# ◆ 7. 当前不能下的结论

目前不能写：

> “观众喜欢系统文，是因为进度条满足胜任感。”

因为现有证据链仍是：

```text
真实行为中的目标 / 反馈 / 进度机制
↓
游戏化研究
↓
系统流结构相似
↓
叙事受众体验【尚缺直接桥梁】
```

同样不能写：

> “系统越多任务、越多数值、越多奖励越好。”

外部奖励研究甚至提示这种简单线性模型存在反作用。

# ◆ 9. 最高价值下一研究节点

不急着继续扩“奖励”。

下一轮最有信息价值的问题是：

# System → Legibility / Control

重点搜索：

- perceived control；
- uncertainty reduction；
- predictability；
- progress feedback；
- game interface / HUD；
- quantified self；
- procedural rhetoric / rule comprehension；
- autonomy support vs controlling structure。

核心要区分两个竞争解释：

```text
A.
系统吸引人
因为它让主角更强

vs

B.
系统吸引人
因为它让世界、目标和成长变得更可读、可预测、可追踪
```

这会决定“系统”最终为 Material Selection Model 新增的是：
- 一个 Advantage 变量；
还是
- 一个更一般的 Legibility / Rule-interface 变量。
