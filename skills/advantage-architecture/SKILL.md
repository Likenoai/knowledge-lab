# Advantage Architecture（优势架构）

诊断故事前提如何给角色建立“相对于环境、对手或普通人”的正向不对称。

## Context pointers（上下文指针）

- 先读取 [../../research/genre-studies/重生/15_优势架构的科学研究映射.md](../../research/genre-studies/重生/15_优势架构的科学研究映射.md)。
- 需要区分优势类型、可用条件与行动空间时，读取 [../../research/genre-studies/重生/16_优势架构第二轮_优势类型可用性与行动空间.md](../../research/genre-studies/重生/16_优势架构第二轮_优势类型可用性与行动空间.md)。
- 当前题材研究不进入 Plot Causality（剧情因果）。不要把 17_优势架构第三轮_优势如何转化为行动.md 当作本 Skill 的默认范围。

## Definition（定义）

Advantage Architecture（优势架构）只研究：

- Advantage Source（优势来源）
- Advantage Legitimation（优势合理化）
- Advantage Type（优势类型）
- Relative Asymmetry（相对不对称）
- Magnitude（优势强度）
- Scope（优势范围）
- Cost（代价）
- Exclusivity（独占性）
- Stability（稳定性）

Payoff（收益）与 Audience Reward（观众心理奖励）是后续层，不属于优势本身。

## Process（执行流程）

◆ **Source（来源）**

优势从哪里出现？例如重生记忆、系统规则、身份、资源、训练、血统或世界规则。

◆ **Legitimation（合理化）**

故事用什么因果或规则解释优势为什么成立？这里只判断前提层的规则完整性，不评价后续剧情表现。

◆ **Type（类型）**

允许多选：

- Information Advantage（信息优势）
- Experience Advantage（经验优势）
- Skill Advantage（能力优势）
- Resource Advantage（资源优势）
- Status Advantage（地位优势）
- Power Advantage（权力优势）

必要时新增类型，但必须说明为什么现有分类无法容纳。

◆ **Relative Asymmetry（相对不对称）**

相对于谁有优势：

- 普通人；
- 对手；
- 当前社会身份；
- 世界平均水平；
- 特定场景中的参与者。

没有参照对象，就不能准确称为“优势”。

◆ **Properties（属性）**

分别判断：

- Magnitude（强度）
- Scope（范围）
- Cost（代价）
- Exclusivity（独占性）
- Stability（稳定性）

如果优势伴随明确代价，同时标记它与 Trade-off Architecture（交换 / 代价架构）重叠。

◆ **Separate payoff（分离收益）**

把“有钱、复仇成功、被认可、获得爱情”等结果放到 Payoff（收益）层，不把结果倒填为优势。

## Completion criterion（完成标准）

完成时必须能回答：

- 主角究竟比谁多了什么？
- 这个优势为什么在设定里成立？
- 优势属于哪种类型？
- 它有多强、覆盖多广、是否有代价、是否独占、是否稳定？
- 哪些内容其实属于 Constraint（约束）、Trade-off（交换）或 Payoff（收益），不应塞进优势架构？
