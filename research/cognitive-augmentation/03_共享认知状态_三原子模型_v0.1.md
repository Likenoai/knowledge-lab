## 1. State 的工作定义

State（状态）不是完整历史，而是：

> **从过去历史中压缩出来、对下一步预测、推理与行动仍然充分的信息。**

因此：

```text
History
↓
Compression
↓
State
```

聊天记录、文档、长期记忆等属于 History / Persistence Infrastructure，不等同于 Cognitive State 本身。

---

## 2. 当前三原子模型

当前候选：

```text
Shared Cognitive State
=
Intent State
+
Model State
+
Commitment / Control State
```

### A. Intent State（意图状态）

回答：

> **我们现在想实现什么？**

可包含：

- Goal
- Values
- Success Criteria
- Scope

本质问题：

> What are we trying to achieve?

---

### B. Model State（模型状态）

回答：

> **我们当前认为世界 / 问题是什么样的？**

可包含：

- Beliefs
- Relations
- Hypotheses
- Evidence / Provenance
- Confidence / Uncertainty
- Unknowns

本质问题：

> What do we currently think is the case?

Uncertainty 不是独立原子，而是 Model 的属性。

Evidence 不是独立原子，而是 Model 的依据 / provenance。

---

### C. Commitment / Control State（承诺 / 控制状态）

回答：

> **我们已经选择了什么、正在沿哪条路径行动、哪些决定已经改变了下一步？**

可包含：

- Commitments
- Active Plan
- Current Focus
- Chosen Branch
- Changed Constraints

本质问题：

> What have we already selected or committed to doing?

当前尚未确定第三原子的最佳名称到底应是 Commitment State 还是更一般的 Control State。

---

## 3. 派生结构

### Active Question

当前假设：

```text
Intent
+
Model
↓
Gap
↓
Active Question
```

因此：

> **Question 可以被理解为 Intent 与 Model 之间的 Epistemic Gap（认识缺口）的显式表征。**

### Open Questions

Open Questions 不是独立状态原子，而是尚未消除的 Epistemic Gaps。

### Memory

Memory 不等于 Cognitive State。

更准确：

> **Memory 是 State Persistence / Reconstruction Infrastructure（状态持久化 / 重建基础设施）。**

### Branch

Branch 不是独立原子。

它更多是 Model + Commitment / Control 的组织视图。

## 5. 当前关键问题

下一步研究：

> **第三原子到底应该是 Commitment State（承诺状态），还是更广义的 Control State（控制状态）？**

需要回答：

1. Commitment 是否已经足以承担跨时间行动连续性；
2. Active Plan / Current Focus 是否可以视为 Commitment 的派生；
3. Cognitive Control 更像“状态”，还是管理这些状态的机制；
4. 是否存在成熟认知 / agent 架构与该三分结构对应；
5. 若使用 Control State，是否会把“状态”与“控制机制”混为一谈。
