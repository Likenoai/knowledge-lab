# Knowledge Structure Mapping Glossary

这里记录用户已经能够正确使用的规范术语。术语只有在实际学习中证明理解后才加入。

## Terms

**Hierarchy（层级）**：  
一组节点被某种一致的上下位 / 排序关系组织起来的结构。层级不是排版形状；判断层级前必须先明确关系类型。

**IS_A / SUBCLASS_OF（是一种 / 子类）**：  
表示一个概念在定义上属于另一个更一般的概念。例如“金毛犬 IS_A 狗”。

**PART_OF（部分—整体）**：  
表示一个对象或概念是另一个整体的组成部分。例如“车轮 PART_OF 汽车”。它不同于 IS_A。

**Instance（实例）**：  
当前模型中的一个具体对象或个案，例如某一个具体角色或某一部具体作品。

**Class / Concept（类 / 概念）**：  
用于表示一类对象或一个一般概念，而不是单一具体实例。

**Dimension / Facet（维度 / 分面）**：  
描述一个对象或模型的一个独立观察轴。

**Value（取值）**：  
某个维度上的一个具体状态或类别。例如 Advantage（优势）可以作为 Relative Effect（相对效应）的一个取值。

**Process / Stage（过程 / 阶段）**：  
表示一个过程本身或流程中的一个阶段。例如在 Research → Synthesis 中，Research 可作为一个阶段节点。

**Relation（关系）**：  
用于连接两个或多个节点、表达它们之间语义联系的关系类型，例如 CAUSES、PART_OF、PRECEDES。
