# 人物系统模型

版本：v1.0

状态：研究版

## 核心定义

人物不是标签，而是一个动态系统。

人物行为来自内部模型：

- Want（外部目标）
- Need（内在需要）
- Fear（恐惧）
- False Belief（错误信念）
- Value System（价值系统）

## 人物变化

角色弧光不是简单变好或变坏，而是内部模型面对现实反馈后的调整。

旧模型无法解释现实
→ 冲突
→ 反馈
→ 修正或坚持

## 设计问题

1. 他相信什么？
2. 为什么相信？
3. 什么事件会挑战他的模型？
4. 他如何选择？
