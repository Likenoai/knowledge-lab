# 经济学母原则：与现有人生原则体系的映射

> 状态：Working Research Map v0.1
>
> 目的：不把经济学基础概念直接注册成人生原则，而是把它们作为 Principle Source Set（原则源集合），检查它们与当前 L0 / P-001～P-011 的重叠、补充与组合生成价值。

## 1. 候选 Principle Source Set

当前先采用 7 个高生成力经济学母原则：

1. **Scarcity（稀缺性）**
2. **Trade-off（权衡）**
3. **Opportunity Cost（机会成本）**
4. **Marginal Analysis（边际分析）**
5. **Incentives（激励）**
6. **Constraints / Feasible Set（约束 / 可行集合）**
7. **Feedback / Interdependence（反馈 / 相互依赖）**

这些条目目前不是新的 Personal Principles（个人原则），而是用于生成、解释和检验原则的基础结构。

## 2. 与当前 L0 的映射

| 经济学母原则 | 对应 / 邻近 L0 | 关系判断 |
|---|---|---|
| Scarcity | Temporal Finitude；Bounded Cognition；Embodiment | 不是新的独立 L0，更像多个有限条件共同产生的资源状态 |
| Trade-off | Multiple Valued Ends & Potential Conflict；Temporal Finitude | 更像由“多目标 + 有限资源”生成的 L1 决策结构 |
| Opportunity Cost | Temporal Finitude；Multiple Valued Ends | 已明确属于 L1 mechanism，不应新增为 L0 |
| Marginal Analysis | 无直接 L0 对应 | 属于分析 / 决策规则，更接近 L2 / Meta-Principle |
| Incentives | Social Interdependence；Structural Embeddedness | 不是单一现实条件，更像行为响应与制度设计机制 |
| Constraints / Feasible Set | Structural Embeddedness & Feasible-Set Constraints；Embodiment；Statefulness | 已被当前 L0 明确覆盖 |
| Feedback / Interdependence | Social Interdependence；Statefulness；Environmental Uncertainty | 横跨多个 L0，更像动态系统机制 |

初步结论：

> **7 个经济学母原则没有要求我们新增一个新的 L0。**

它们更有价值的角色，是把当前 L0 转译成更可行动的 L1 / L2 结构。

## 3. 与当前 P-001～P-011 的映射

| 经济学母原则 | 已有原则 | 当前覆盖情况 |
|---|---|---|
| Scarcity | P-001 不可逆配置；P-011 边际配置 | 已部分覆盖 |
| Trade-off | P-003 显性机会成本；P-004 不可替代优先 | 已部分覆盖，但缺一个更一般的“优先级必须排除”表达 |
| Opportunity Cost | P-003 显性机会成本；P-011 边际配置 | 覆盖较强 |
| Marginal Analysis | P-011 边际配置 | 已直接吸收 |
| Incentives | 暂无强对应 | 明显缺口 |
| Constraints / Feasible Set | P-006 Position Before Decision | 已部分覆盖，但 P-006 更偏“改善位置”，不是一般约束识别 |
| Feedback / Interdependence | P-010 递归构建；P-009 承担可控部分 | 已部分覆盖 |

## 4. 当前最值得继续生成的缺口

按 Decision Delta（决策增量）和 Marginal Uniqueness（边际独特性）筛选，当前最值得进一步评估的不是 7 条全部注册，而是下面 4 个组合候选。

### C-01｜Priority Requires Exclusion（优先级意味着排除）

生成关系：

```text
Scarcity
+
Multiple Valued Ends
+
Trade-off
+
Opportunity Cost
↓
不可能同时最大化所有重要目标
↓
真正的优先级必须体现为资源排除
```

候选表达：

> **如果所有事情都同等优先，就没有形成真正的优先级；优先级必须体现在时间、注意和资源的排除性配置上。**

价值：
- 直接作用于学习、项目、职业、关系、研究；
- 与 P-003 相邻，但比“重大承诺的机会成本”更一般；
- 可能具有较高显式保留价值。

### C-02｜Design Incentives, Not Just Intentions（设计激励，不只依赖意愿）

生成关系：

```text
Bounded Cognition
+
Incentives
+
Repeated Behavior
↓
意愿不能稳定支撑高频行为
↓
改变默认成本 / 收益 / 摩擦
```

候选表达：

> **对于需要长期重复的行为，不只要求自己“想做到”，而要调整奖励、成本、摩擦和默认选项，让正确行为更容易发生。**

价值：
- 当前注册表明显缺少“激励 / 环境结构”原则；
- 与 Clear Thinking 的 default behavior 有直接衔接；
- 对学习、健康、工作习惯、产品设计都可能高频使用。

### C-03｜Preserve Option Value under Uncertainty（不确定下保护选择权）

生成关系：

```text
Environmental Uncertainty
+
Statefulness / Irreversibility
+
Opportunity Cost
↓
未来信息仍会到来
且部分选择难以撤销
↓
可逆性本身具有价值
```

候选表达：

> **当未来高度不确定、且错误选择难以撤销时，优先保留低成本试错、退出和转向的空间。**

价值：
- 对职业、创业、合作、重大承诺高度相关；
- 与 P-006 有联系，但它关注 Optionality，而 P-006 关注 Decision Position；
- 很可能是高价值个人原则候选。

### C-04｜Model the Response, Not Only the Action（不仅分析行动，也分析反馈）

生成关系：

```text
Interdependence
+
Feedback
+
Incentives
↓
自己的行为会改变他人的行为
↓
结果不能只按第一阶效应判断
```

候选表达：

> **做重要选择时，不只问“我做这件事会怎样”，还要问“别人和系统会怎样回应我的行为”。**

价值：
- 可用于谈判、合作、组织、商业、关系；
- 与用户正在训练的“二阶效应 / 信号识别”高度兼容；
- 目前注册表中没有一个直接覆盖 strategic response（战略回应）的原则。

## 5. 暂不单独注册的经济学母原则

当前不建议直接把以下条目注册为人生原则：

- Scarcity
- Trade-off
- Opportunity Cost
- Marginal Analysis
- Constraints / Feasible Set
- Feedback / Interdependence

原因不是它们不重要，而是：

> 它们更适合作为生成和解释结构；如果直接进入前台原则集，容易得到“正确但不够可调用”的抽象概念。

Incentives 也暂不直接注册，而是优先测试它是否能形成 C-02 这样的高 Decision Delta 原则。

## 6. 当前建议的原则生成优先级

不机械研究全部 4 个候选。

按照 P-011 Marginal Allocation Principle：

```text
优先研究：
C-03 不确定下保护选择权
C-02 设计激励，不只依赖意愿

其次：
C-01 优先级意味着排除

后续：
C-04 不仅分析行动，也分析反馈
```

理由：

- C-03 对重大人生决策损失控制价值高；
- C-02 高频、可重复、能直接改变日常行为；
- C-01 很重要，但与现有 P-003 / P-011 重叠度更高；
- C-04 很有生成力，但需要进一步明确与二阶效应、博弈论、社会相互依赖之间的边界。

## 7. 对原则体系结构的更新

当前可以把经济学的作用理解为：

```text
L0 Decision Reality Conditions
↓
经济学母原则 / 决策结构
Scarcity / Trade-off / Opportunity Cost /
Marginal / Incentives / Feasible Set / Feedback
↓
Composite / Derived Principles
↓
Personal Principle Registry
```

因此，经济学不是单独再建一套“经济学人生原则”。

更高价值的做法是：

> **把经济学作为 Principle Generator（原则生成器）之一，与心理学、决策科学、社会科学等共同向人生原则注册表供给候选原则。**

## 8. 下一步

下一步优先对 **C-03 Preserve Option Value under Uncertainty** 做小规模验证：

1. 检查与 real options、irreversibility、option value、robust decision making 的成熟理论对应；
2. 明确什么时候“保留选择权”优于“立即承诺”；
3. 寻找反例：等待成本、窗口消失、承诺本身创造价值；
4. 判断它与 P-006 Position Before Decision 是否独立；
5. 如果 Decision Delta 足够高，再进入原则注册表。
